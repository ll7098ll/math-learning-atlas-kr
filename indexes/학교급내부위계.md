# 학교급 내부 관계와 위계 색인

435개 모든 기준에서 같은 학교급 내부의 방향 관계와 의미 연결을 찾아본다. 방향은 자체 분석한 의미 확장과 과제별 조건에 한정하며 고정된 학습·이수 순서가 아니다. 연결 이유와 조건은 각 상세 문서에서 읽는다.
