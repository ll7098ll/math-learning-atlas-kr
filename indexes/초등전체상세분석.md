# 초등 수학 전체 상세 분석 안내

초등 121개 성취기준 모두에 세부 사고와 진단 및 중고등 연결을 포함하는 상세 초안을 작성했다. 기존 세 초안은 보존하고 나머지 118개를 추가했다. 학생 반응으로 검증된 학습 경로와 진단 도구의 완료를 뜻하지 않는다.

[프로젝트 안내](../README.md) · [진행 현황](진행현황.md) · [중고등 연결 지도](초중고연결지도.md)
