# 수학 내용 체계 진행 현황

전체 목록화와 상세 사고 분석의 진행률을 각각 관리한다. 초안 작성은 연구 검토나 학생 반응 검증의 완료를 뜻하지 않는다.

| 학교급 | 목록화 | 상세 분석 초안 | 검토 완료 | 학생 반응 검증 |
|---|---:|---:|---:|---:|
| 초등학교 | 121 | 121 | 0 | 0 |
| 중학교 | 60 | 60 | 0 | 0 |
| 고등학교 | 254 | 254 | 0 | 0 |

## 다음 작업

1. 전체 상세 초안의 수학적 논증과 교육과정 적용 범위를 영역별로 검토한다.
2. 중고등 연결의 중간 개념과 성립 조건을 보강하고 대안 경로를 비교한다.
3. 문헌의 원연구를 정독하여 자체 사고 분석과 연구 결과의 대응 범위를 확인한다.
4. 가능한 경우 진단 질문에 대한 실제 학생 반응으로 분석을 수정한다.

전체 자료 보완의 최신 진행과 완료 조건: [전체 자료 보완 진행](../docs/전체자료보완진행.md). 내용 체계 항목의 자체 의미 대조, 원문 이미지 대조, 문헌 검토와 실제 검증을 구별해 관리한다.
