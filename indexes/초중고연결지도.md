# 초등에서 중고등으로 이어지는 수학 연결 지도

각 출발 목표에서 어떤 사고가 유지되고 무엇이 새로 필요한지 설명하는 경로를 모았다. 의미 연결과 확장은 모든 학습자에게 필요한 고정된 선수 순서를 뜻하지 않는다. 공식 성취기준의 코드는 전체 목록과 대조했다.
