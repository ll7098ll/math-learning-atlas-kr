## 핵심 의미와 목표 수행

밑 a가 양수일 때 지수법칙을 유지하도록 0과 음의 지수, 분수 지수의 값을 정한다. 무리수 지수는 가까워지는 유리수 지수의 거듭제곱값을 통해 이해한다.

## 대표 과제와 성공한 수행

a>0에서 a⁰, a⁻¹, a^(1/2)를 이미 아는 지수법칙과 연결한다. a^√2를 설명할 때 어떤 유리수 지수를 차례로 쓸 수 있는지 말한다.

**기대하는 수행**

√2를 가까워지는 유리수로 근사하고 a의 해당 거듭제곱이 가까워지는 양의 값을 a^√2로 이해한다.

### 하위 목표와 연결된 과제

밑이 양수인 조건에서 0·음의 정수·유리수·실수 지수로 의미를 확장한다. 실수 지수는 유리수 근사를 통한 직관으로 다룬다.

[전체 목표 원장](../docs/하위목표과제별위계.md#12대수01-02) · [공식 내용 체계 대응](../docs/공식내용체계대응표.md)

#### 법칙을 보존하는 분수 지수

밑 4에서 4⁰, 4⁻¹, 4^(1/2), 4^(3/2)를 구하고 a^(m/n)의 의미를 설명한다.

**이 과제로 확인할 목표**

- 유리수 지수 확장 · 기존 법칙을 보존하도록 0·음수·분수 지수를 정한다.

**과제의 공통 조건**

- a>0, m은 정수, n은 양의 정수다. 0⁰이나 음의 밑의 일반 실수 지수는 이 확장에 넣지 않는다.

##### 법칙을 보존하는 분수 지수

**이 풀이에서 함께 필요한 조건**

- 거듭제곱근의 뜻을 안다.
- 자연수 지수법칙을 안다.

4³/4³=1이므로 4⁰=1로 정하고 4⁻¹=1/4로 정한다. 제곱하면 4가 되는 양의 값으로 4^(1/2)=2다.

4^(3/2)=2³=8이다. 일반적으로 a^(m/n)=(ⁿ√a)^m로 정한다. 양의 밑과 양의 근을 택해 같은 유리수의 다른 표현에도 값을 보존한다.

1,1/4,2,8이며 분수 지수는 양의 거듭제곱근으로 해석한다.

**확인 질문**

4^(1/2)에 −2도 포함되는가?

**기대하는 설명**

이 지수 표기는 양의 대표값 2 하나다.

#### 유리수로 √2 지수에 접근

1.4<1.41<√2<1.42<1.5를 이용해 2^√2의 의미를 설명한다.

**이 과제로 확인할 목표**

- 실수 지수 설명 · 유리수 근사값의 거듭제곱으로 무리수 지수의 양의 값을 직관적으로 설명한다.

**과제의 공통 조건**

- 밑 2는 1보다 크다. 실제 값을 엄밀하게 구성하는 증명이나 미분·극한 계산을 요구하지 않는다.

##### 유리수로 √2 지수에 접근

**이 풀이에서 함께 필요한 조건**

- 유리수 지수의 값을 이해한다.
- 무리수의 개념을 안다.

2^1.4<2^1.41<2^√2<2^1.42<2^1.5로 값을 좁힌다. 유리수 근사를 더 촘촘하게 해 양의 값 하나에 가까워진다고 직관적으로 이해한다.

2^√2≈2.66514다. (1/2)^√2에서는 밑이 0과 1 사이여서 지수의 대소에 따른 값의 순서가 반대다.

양의 밑의 유리수 지수를 실수 입력으로 연속적으로 확장하는 직관이다.

**확인 질문**

밑이 음수여도 같은 실수 지수 확장을 그대로 쓰는가?

**기대하는 설명**

교육과정의 유리수·실수 지수 확장은 양의 밑에서 다룬다.

## 수학적 의미와 성립 조건

지수법칙의 일관성과 양수 밑의 근사적 연속 확장을 구별한다. 밑 a는 양수다. 무리수 지수의 값은 단순 반복 곱의 횟수로 정의하지 않는다.

**적용 조건**

- 밑 a는 양수다. 무리수 지수의 값은 단순 반복 곱의 횟수로 정의하지 않는다.

**교육과정 범위**

실수 지수의 기본 전제는 양수 밑이며 엄밀한 해석학적 구성 전체를 성취 요구로 추가하지 않는다.

## 수행 과정과 대안 경로

### 대표 과제의 해설

a³/a³=1이므로 지수 차 법칙을 유지하려면 a⁰=1이고 a⁻¹=1/a여야 한다. (a^(1/2))²=a이면서 양수인 값을 선택해 a^(1/2)=√a로 정한다. √2를 가까워지는 유리수로 근사하고 a의 해당 거듭제곱이 가까워지는 양의 값을 a^√2로 이해한다.



경로별 조건을 구별하며, 사고 요소의 나열을 고정된 발달 순서로 해석하지 않는다.

## 표현 사이의 대응

- 지수의 유리수 근사와 양의 밑에서의 출력 변화를 표로 비교한다.

## 학습 활동과 피드백

- 지수가 2, 1, 0, −1로 하나씩 줄 때마다 값을 a로 나누어 표를 채운다. √2에 가까워지는 유리수 1.4, 1.41, 1.414도 순서대로 적는다.

### 공식 내용 체계에 따른 보완 관찰

내용 요소: 지수와 로그 표현의 편리함 인식

보완 이유: 유리수 지수와 로그가 곱·자릿수·변화 배율을 간결하게 나타내는 이유를 성찰한다.

발문: 큰 양의 정수 N의 자릿수를 log₁₀N의 구간으로 표현하는 방법과, 곱셈 관계를 로그의 덧셈 관계로 바꾸는 방법의 편리함과 조건을 설명하라.

기대 설명과 관찰: N>0이며 3≤log₁₀N<4이면 네 자리다. 곱·몫 법칙의 양의 입력 조건을 유지하고 로그가 합을 같은 방식으로 나누지 않음을 구별한다.

관찰 설계 초안이다. 실제 학생의 반응·선택·수정 기록으로 판단하며 계산 정답만으로 태도나 흥미를 판정하지 않는다.

### 문헌을 참고한 추가 관찰 EG-P2

발문: 같은 길이의 시간 구간에 같은 배율을 적용하는 연속 지수 모형에서 하루 배율이 9라면 반나절 배율을 구하라. 하루 배율을 2로 나누지 않는 이유도 설명하라.

기대 설명: 반나절 배율의 제곱이 9이고 배율은 양수이므로 9의 1/2제곱인 3이다. 두 시간 구간의 배율은 더하는 대신 곱한다.

해석 범위: 시간 간격은 덧셈으로, 배율은 곱셈으로 결합하며 양의 값을 선택하는지 확인한다.

## 근거와 검토 상태

공식 목표와 범위의 근거는 교육부 고시 제2022-33호 12대수01-02이다. 과제 해설·사고 분석·관계는 자체 수학적 분석과 교수 설계 초안이다.

과제별 수학적 자체 분석 초안

실수 지수의 기본 전제는 양수 밑이며 엄밀한 해석학적 구성 전체를 성취 요구로 추가하지 않는다.

풀이의 각 수행과 정당화 이유를 개별 작성했다.
