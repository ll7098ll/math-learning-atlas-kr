# 전체 개념군 연결과 위계 확장 결과

작성일: 2026년 10월 29일

[연결과 위계](https://math-learning-atlas-kr.gptpro2908176.chatgpt.site/#view=hierarchy)의 탐색 범위를 46개 전체 개념군과 435개 성취기준으로 확장했다. 기존 성취기준 사이 관계 1,518개를 보존하고, 각 개념군과 개별 관계의 위계 검토 상태를 표시한다.

## 제공 범위와 상태

| 구분 | 개념군 수 | 표시와 의미 |
|---|---:|---|
| 의미 확장 초안 | 33 | 해당 개념군에 닿는 기존 의미 확장 기록이 있음. 선수 위계는 미검토 |
| 방향 위계 미검토 | 13 | 의미 확장 방향이 기록되지 않음. 의미 연결과 교육과정 위치는 탐색 가능 |
| 독립 검토 완료 | 0 | 검토 완료로 승격한 개념군 없음 |
| 과제별 자체 점검 사례 | 기존 3개 시범 | 분수·비율·넓이의 조건 묶음과 대안 경로를 별도로 보존 |

위의 33개와 13개는 전체 46개를 나눈 수다. 세 과제별 사례는 별도 자료이며 개념군 수에 더하지 않는다. 개념군에 속하는 기준뿐 아니라 그 기준에 직접 닿는 다른 개념군의 기준도 맥락으로 제공한다.

이번 확장은 기존 관계의 탐색과 검토 상태를 전체 범위로 제공하는 작업이다. 46개 전체의 필수 선수 관계를 새로 검증한 결과가 아니다. 의미 확장 방향, 공식 학년군 위치, 필수 선수 조건을 구별한다.

## 화면에서 할 수 있는 일

- 46개 전체 목록에서 의미 확장 초안과 방향 위계 미검토를 구별하고, 상태별로 필터링한다. 상태는 개념군을 펼치기 전에도 보인다.
- 모든 성취기준을 해당 개념군의 목표로 선택한다. 전체 연결망의 선택 노드, 기준 상세, 개념군 목록에서도 바로 진입한다.
- 확장 위계 초안 보기에서 선택 목표에 직접 닿는 앞선 의미와 이후 의미 확장을 확인한다. 기준을 눌러 목표를 바꾸며 이어서 탐색한다.
- 직접 의미 연결 보기에서 순서가 정해지지 않은 관계도 읽고, 교육과정 위치 보기에서 소속 기준을 학교급별로 살펴본다.
- 개념군 전체의 의미 확장 기록과 모든 소속 기준을 펼쳐 본다. 관계를 선택하면 기존 이유·적용 범위·조건·추가 사고·한계·출처를 읽는다.
- 학교급 강조를 바꿔도 목표와 연결 맥락은 유지한다. 범위 밖 항목은 별도 배경과 글자로 표시한다.

노드와 관계에는 위계 미검토 상태를 붙였다. 의미 확장 초안은 파란 표시, 미검토 상태는 황갈색 점선 표시로 구별하며 글자도 함께 제공한다. 학습 선수성의 독립 검토와 학생 반응 검증은 현재 0건으로 표시한다.

기록이 없는 방향에는 미검토 또는 미기록 상태를 표시한다. 그 구간을 선수 개념이 없는 기초 단계로 취급하지 않는다. 의미 연결과 대조에는 학습 선후를 부여하지 않고, 상충하는 방향은 순서를 정하지 않은 검토 대상으로 남긴다.

## 자료와 로딩

생성기는 `scripts/build_concept_pathways.py`다. 배포용 소스의 공통 색인, 개념 분류, 관계, 시범 자료가 같은 버전인지 확인한 뒤 개념군별 자료를 생성한다. 일반 포털 자료 생성기에서도 이어서 실행하도록 연결했다.

전체 상태 색인은 21,672바이트다. 개념군을 선택하면 해당 개념군 파일만 읽으며, 가장 큰 개념군 파일은 229,323바이트다. 수치는 압축 전 기준이다. 개념군 직접 진입 때문에 전체 관계 묶음을 읽지 않는다. 파일 주소에 자료 내용의 해시를 넣고, 기존 요청 공유와 버전 일치 검사를 유지한다.

각 관계의 원래 ID·유형·설명·성립 조건·출처는 보존한다. 위계 미검토 상태와 표시 역할을 별도로 추가하며 원래 연결 상태를 덮어쓰지 않는다. 학년, 코드 번호, 유사도만으로 선수 관계를 생성하지 않는다.

## 검증

배포용 소스의 다섯 검사가 통과했다.

- `tests/test_all_concept_pathways.mjs`: 46개 개념군, 435개 기준, 1,518개 원본 관계와 근거 보존, 828개 범위와 보기 조합, 435개 상세의 진입 링크, 상태 필터, 방향 추론 제한, 순환과 잘못된 ID, 선택 자료만 읽는 동작.
- `tests/test_pathways.mjs`: 세 시범 위계와 36개 범위·경로 조합, 조건 보존과 요청 재시도.
- `tests/test_network_model.mjs`: 기존 전체 연결망의 435개 노드와 관계·배치·필터 보존.
- `tests/test_flow_network.mjs`: 기존 개념 흐름 지도와 직접·간접 연결 동작 보존.
- `tests/test_concept_flows.mjs`: 전체 주 분류와 과목·기준 검색 및 관계 접근성 보존.

로컬 브라우저에서는 시범 밖인 등식·방정식·항등식의 확장 근거와 학교급 밖 목표 유지를 확인했다. 행렬 개념군은 방향 기록 0건과 위계 미검토 상태를 표시하며, 직접 의미 연결은 계속 탐색할 수 있었다. 360·560·768·1280px에서 페이지 가로 넘침 없이 표시되는 것을 확인했다.

실제 배포 화면에서도 46개 목록, 의미 확장 초안 33개, 방향 위계 미검토 13개, 미검토 필터의 13개 결과와 방정식 개념군 진입을 확인했다. 검증 화면은 `tmp/all-concept-qa/deployed-equation.png`에 보관했다.

## 배포와 후속 검토

배포 소스는 최신 연결망 기능을 보존한 `tmp/pathways-release`다. 커밋 `24e4934189400aac2f16d67cfb9292352ecd2461`을 기존 소유자 전용 사이트에 배포했고 상태는 성공이다. 배포본에는 재생성 스크립트와 검사가 포함되어 있다.

각 개념군의 실제 과제별 선수성, 대안 풀이의 조건, 교사의 독립 검토와 학생 반응은 계속 검토할 대상이다. 현재의 전체 탐색 범위를 독립 검토 완료율로 표시하지 않는다.
