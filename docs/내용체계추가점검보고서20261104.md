# 수학 내용 체계 추가 점검 보고서

후속 조치: 아래는 수정 전 점검 기록이다. 현재 반영 상태는 [보완 결과](내용체계보완결과20261104.md)에서 확인한다.

작성일: 2026년 11월 4일 · 작성: Codex · 판정: 추가 정리 필요

**435개 성취기준과 870개 하위 목표의 작성 누락은 없지만, 내용 체계 정리가 모두 끝난 상태는 아니다.** 이번 점검에서 일반각 설명의 수학 오류, 초등 시간 분석의 학년 범위 혼입, 확률 설명의 과잉 일반화를 확인했다. 공식 내용 체계표의 대응 원장, 상세 문서와 목표 원장의 연결, 대안 풀이와 기존 관계의 진단 정보도 보완해야 한다.

기존 자동 검사 28개는 모두 통과했다. 따라서 아래 문제는 파일 개수나 검사 통과 여부만으로는 발견되지 않는 내용·범위·기록의 공백이다. 기존 [1차 완성 보고서](전체위계1차완성보고서.md)는 전체 초안과 탐색 구조를 제공한 성과로 읽되, 내용상의 잔여 문제가 없다는 판정으로 확대해서는 안 된다.

## 먼저 바로잡을 내용

### 일반각에서 서로 반대인 동경을 같다고 설명함

**우선 수정 · 12대수02-01.** [대수·미적분Ⅰ 목표 원장](../data/goal_hierarchy_algebra_calculus_one.json) 2704행과 [원고 작성 스크립트](../scripts/author_algebra_calculus_one.py) 108행에는 “450°=5π/2, −90°=−π/2이며 모두 90°와 같은 동경”이라고 적혀 있다.

450°와 90°의 차이는 360°이므로 같은 동경이다. 그러나 −90°와 90°의 차이는 −180°이므로 서로 반대다. **“450°는 90°와, −90°는 270°와 같은 동경이다”**로 고쳐야 한다. 라디안 환산값과 호의 길이 계산은 옳다.

[기존 검사](../scripts/check_algebra_calculus_one.py) 39행은 라디안 환산을 확인하지만 이 문장의 동경 비교는 확인하지 않는다. 수정 뒤에는 원장과 작성 스크립트를 함께 갱신하고, 각도 차가 360°의 정수배인지 확인하는 검사를 추가해야 한다. [기존 상세 문서](../analyses/12대수02-01.md)의 450° 설명 자체는 옳으므로 수정 범위를 구별한다.

### 초등 1~2학년 시간 분석에 초 단위가 섞임

**우선 수정 · 2수03-07·2수03-08·2수03-09.** 세 상세 문서의 71행에 공통으로 “복합 단위→분과 초：60 관계를 유지한다”가 남아 있다. 공식 교육과정에서 초 단위의 관계·시각·시간 계산은 **4수03-13·4수03-14**, PDF 27쪽에 제시된다. 1~2학년 해당 기준의 시간·분·일·주·개월·년 범위와 구별해야 한다.

직접 근거는 [시각 읽기](../analyses/2수03-07.md), [시간과 분](../analyses/2수03-08.md), [달력 관계](../analyses/2수03-09.md) 및 [초등 보강 원본](../data/revisions_elementary.json) 7885·7973·8081행이다. [공통 원고](../scripts/analysis_content.py) 245행에도 같은 표현이 있다.

특히 달력 관계 문서는 대표 과제가 ‘2주 뒤 날짜와 달별 일수’인데 설명 경로 1·2는 모형 시계·정각·세로셈의 공통 문구다. 기준별로 필요한 표현 전환과 풀이 경로를 다시 대응시켜야 한다. 단순히 출력 문서에서 ‘초’만 지우면 원본 재생성 때 재발할 수 있다.

### 확률 설명에서 배반 조건을 지나치게 일반화함

**범위 수정 · 12확통02-02.** [확률·통계 목표 원장](../data/goal_hierarchy_probability_statistics.json) 1914행은 일반 덧셈정리를 설명한 뒤 “교집합이 공집합인 배반 사건에서만 빼는 항이 0”이라고 쓴다.

현재의 공정 주사위 과제에서는 맞지만 일반 확률까지 확장하면 맞지 않는다. [0,1]에서 균등하게 값을 정할 때 A=[0,0.5], B=[0.5,1]이면 교집합은 {0.5}로 비어 있지 않아도 그 확률은 0이다. **“배반 사건이면 빼는 항이 0이다”**로 바꾸거나 현재의 유한 표본공간에 한정해야 한다. 해당 주사위 문제의 답 2/3은 옳다.

## 아직 구조화가 덜 된 부분

### 공식 내용 체계표와 해설의 반영 위치를 전수 대조할 수 없음

공식 PDF 13쪽의 내용 체계표에는 핵심 아이디어, 지식·이해, 과정·기능, 가치·태도가 구별되어 있다. 현재의 [개념 분류](../data/concept_taxonomy.json)는 성취기준 435개를 연구 목적의 46개 개념군으로 묶은 자료다. 공식 표의 항목마다 원문·쪽수·성취기준·하위 목표·과제·반영 상태를 연결한 별도 대응 원장은 확인되지 않았다.

따라서 **성취기준 작성률 100%만으로 가치·태도나 여러 기준을 관통하는 핵심 아이디어까지 빠짐없이 정리됐다고 판정할 수 없다.** 예를 들어 수와 연산 표의 ‘풀이 과정과 결과를 반성하는 태도’를 어떤 과제와 관찰 근거로 다루는지 전수 추적할 수 있어야 한다. 이는 [기존 포털 계획](수학교육과정포털계획.md) 146행에서도 별도 확인 대상으로 남겨 둔 범위다.

해설·적용 시 고려 사항도 비슷하다. 목표 원장 435개에 텍스트 대조 상태와 범위 설명이 있지만, 어느 해설 항목을 어느 과제에 반영했는지에 대한 항목별 대응표는 없다. 실제 개별 범위 보강은 존재하므로 ‘해설 검토를 하지 않았다’는 뜻은 아니다. 공식 표와 해설을 행 단위로 목록화하고 반영·보류·해당 없음의 이유를 기록하는 작업이 필요하다.

### 목표 원장에 보강한 내용을 독립 상세 문서에서 찾을 수 없음

**확인 사례 · 2수01-01.** [초기 수 목표 원장](../data/goal_hierarchy_early_number.json)에는 수의 쓰임을 구별하는 과제와 짝수·홀수 과제가 있다. 그러나 [상세 분석 문서](../analyses/2수01-01.md)는 구슬 17개 세기·배열 변경·0을 중심으로 설명하며, 짝수·홀수 과제나 전체 하위 목표 원장으로 가는 링크는 없다. 수의 필요성은 공식 원문 인용에만 등장한다.

자료 전체에서 사라진 내용은 아니지만, ‘상세 분석’만 읽으면 보강된 범위를 놓친다. 해당 문서가 다루는 대표 수행의 범위를 밝히고, 전체 목표·진단으로 연결해야 한다. 이후 같은 현상이 다른 복합 기준에도 남아 있는지 전수 확인할 필요가 있다. 이번 한 사례를 전체 문서의 누락 건수로 확대하지 않았다.

### 198개 과제의 대안 검토란이 공통 주의문에 머무름

565개 과제 중 단일 경로는 504개, 복수 경로는 61개다. **단일 경로라는 사실 자체는 결함이 아니다.** 다만 단일 경로 198개의 `alternative_review`에는 대안을 검토한 결과나 제외 이유 대신 ‘다른 과목 전체의 필수 이수 순서가 아니다’와 같은 다섯 종류의 공통 주의문만 있다.

| 원장 묶음 | 해당 과제 수 |
|---|---:|
| 대수·미적분Ⅰ | 43 |
| 미적분Ⅱ·기하 | 38 |
| 확률과 통계·실용 통계 | 33 |
| 경제·인공지능 | 40 |
| 직무·문화·탐구 | 44 |
| 합계 | 198 |

[전체 위계 완성 계획](전체위계완성계획.md) 78·122행은 실질적 대안이 없으면 그 이유를 기록하도록 했고, [1차 완성 보고서](전체위계1차완성보고서.md) 18행은 그 이유를 보존했다고 쓴다. 이 198개는 해당 완료 주장을 뒷받침하는 기록이 부족하다. 이를 198개의 수학적 오류나 198개의 누락 경로로 해석해서는 안 된다.

구체적으로 **12확통02-06**은 빨강 3개·파랑 2개에서 비복원으로 두 번 뽑는 과제다. [원장](../data/goal_hierarchy_probability_statistics.json) 2190행의 풀이에는 조건부확률 `3/5×2/4`와 조합 `C(3,2)/C(5,2)`가 함께 나오지만 구조화한 경로는 조건부확률 하나다. 조합법을 같은 확률 계산 목표의 대안으로 볼지, 곱셈정리 설명의 보조 검산으로 볼지 먼저 판정해야 한다. 전자이면 별도 경로·조건을 기록하고, 후자이면 검산이라는 역할을 명시한다.

### 기존 관계의 확인 질문과 검토 범위가 충분히 연결되지 않음

기준 간 관계 2,239개 중 **1,518개에는 관계별 확인 질문이 없고**, 기대 설명이 기록된 것은 140개다. 실제 [9수02-14 상세 문서](../analyses/9수02-14.md) 90행 이후의 학교급 간 관계 표에서도 확인 질문 열이 비어 있다. 새 목표·과제 원장에 있는 진단과 기존 관계의 질문은 별도 자료이므로, 이 수치를 ‘목표 1,518개 누락’처럼 읽으면 안 된다.

검토 상태도 두 층이다. 관계 자료 자체에는 `self_checked` 661개·후보 60개·상태 필드 없음 1,518개가 있고, 영속 위계 검토 원장에는 145개가 등재되어 있다. **원장 밖 2,094개 중 516개에는 자체 분석 상태가 있으므로 모두 미검토라고 부르면 부정확하다.** 자체 분석과 선수성 검토의 범위를 분리해 표시하고 실제 검토자·날짜·대상 과제와 연결해야 한다.

우선 학습 경로에서 사용하는 관계부터 고유 질문·기대 설명을 보완하거나 관련 목표·과제 ID를 연결한다. 모든 의미 연결에 필수 선수 방향을 부여하거나 기존 기록을 일괄 완료 처리할 작업은 아니다. 근거는 [관계 자료](../data/revised_relations.json), [위계 검토 원장](../data/hierarchy_review_registry.json), [집계 기록](../data/content_gap_findings_2026-11-04.json)이다.

## 상태 관리와 이미 알려진 후속 작업

현재 [진행 현황](../indexes/진행현황.md) 22행은 통합 감사를 ‘수행 중’이라고 쓰고, README와 1차 완성 보고서는 ‘자체 점검 완료’라고 쓴다. 최신 상태를 **‘1차 자체 점검 완료, 추가 점검에서 확인된 내용 보완 진행 전’**으로 맞추고 본 보고서의 남은 항목을 연결할 필요가 있다.

또한 [목표 원장 로더](../scripts/goal_hierarchy.py) 36·37행은 상태가 반드시 `self_checked`이고 독립 검토·학생 검증이 모두 거짓이어야 한다고 검사한다. 실제 파일을 바꾸지 않은 메모리 실험에서 상태 변경, 독립 검토 표시, 학생 검증 표시가 각각 거부됐다. 지금의 0건 기록에는 문제가 없지만, 향후 검토 근거가 생겨도 이 로더로는 상태를 올릴 수 없다. 증거 없는 승격은 막으면서 근거 있는 단계 전환을 허용하도록 로더와 관련 검사를 정비해야 한다.

## 재현 자료와 검토의 한계

재검사는 다음 명령으로 수행할 수 있다. 기존 원고나 포털을 재생성하지 않고 지정한 감사 JSON만 쓴다.

```text
python scripts/audit_content_gaps.py --output data/content_gap_audit_2026-11-04.json
```

이 PC에서는 일반 `python` 명령이 Windows 별칭이어서 앱에 포함된 Python 실행 파일로 같은 명령을 수행했다. 실제 실행 경로와 검사별 출력은 재검사 기록에 있다.

구조·개수·대안 문구·검토 상태는 전수 집계했다. 의미 검토에는 미적분Ⅱ·기하 44개 과제, 대수 앞부분 22개 과제, 확률·통계와 초등 수·시간 및 일부 중학교·공통수학 사례를 포함했다. 미적분Ⅱ·기하의 읽은 44개 과제에서는 새로운 확정 계산 오류를 찾지 못했다. 다른 모든 문장의 수학적 무오류나 교수 효과까지 입증한 보고서는 아니다.
