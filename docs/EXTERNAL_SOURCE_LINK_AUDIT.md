# 외부 문헌 링크 재점검

점검일은 2026년 11월 26일(한국시간)이다. 직전 배포에서 두 사이트의 435개 성취기준 상세와 원문 상세를 점검할 때 확인하지 못한 외부 주소 38개를 다시 검사했다. 같은 논문을 가리키는 주소가 두 개면 주소별로 집계했다.

- **20개 교체.** 발행처, 정부·대학 저장소, 교육기관 및 해당 출판물을 공개 배포한 기관에서 같은 문헌을 열었다. DOI 또는 제목·저자·권호·언어와 판본을 대조했다. 출판본과 저자 원고는 아래에 구분했다.
- **1개 원 주소 재확인.** HTTP 요청에서 원문 PDF를 확인했고 Chrome에서는 403이 계속되었다.
- **17개 원문 또는 WWC 개별 검토 접근 미확인.** 기존 링크를 유지했다. 출판사의 403, 기관 저장소의 접근 제한, WWC 응답 시간 초과는 이 점검 환경의 결과다.

검사는 Chrome의 공개 탐색과 HTTP GET을 이용했다. 응답이 200이어도 접근 확인 화면, 서지·초록 페이지만 열리는 경우에는 전문을 확인한 것으로 집계하지 않았다. 교체는 상세 화면의 링크에 적용하며 원장의 DOI와 검토 기록은 유지한다.
