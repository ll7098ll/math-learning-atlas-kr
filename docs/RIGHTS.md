# 자료 이용·권리와 공개 범위

이 문서는 현재 저장소의 공개 준비 상태를 기록합니다. 자체 코드·문서에 적용할 라이선스를 아직 선택하지 않았으므로 임의의 MIT·Apache·CC 라이선스 파일을 추가하지 않았습니다. 최종 공개 라이선스는 저장소 소유자가 선택해야 합니다.

## 파일별 구분

| 자료 | 현재 처리 |
|---|---|
| 자체 코드·분석·검토 노트 | Git 후보에 포함. 전체 프로젝트 라이선스 미지정 |
| 공식 교육과정 PDF | 로컬 보존, `*.pdf` 규칙으로 Git 기본 제외 |
| 외부 문헌 PDF | 공개된 파일이어도 일괄 재배포하지 않음. Git 기본 제외 |
| `data/source_review_images/` 원문 이미지 | Git 기본 제외 |
| `data/literature_evidence/` 자체 JSON 노트 | 포함. 원문 파일과 구분 |
| `data/teaching_examples/` CSV | 포함. 가상·모형·출처 자료의 표시 유지 |
| `tmp/`, `.openai/`, 과거 중첩 사이트 저장소 | Git 제외. 로컬 작업 이력 유지 |

문헌 원장의 `redistribution_license`, `license_location`, `license_statement`, `snapshot_kind`는 출처별로 기록한 근거입니다. 일부 문헌에 기록된 CC 또는 Public domain 표시는 다른 문헌이나 프로젝트 전체로 확장하지 않습니다. 현재 기본 제외보다 넓게 원문을 공개하려면 해당 파일의 근거와 조건을 먼저 확인합니다.

## 원문 없이 사용할 수 있는 범위

GitHub 파일만으로 포털의 성취기준·상세 분석·목표·관계·과제를 탐색하고, 공개 파일 대상 검사와 포털 모델 검사를 실행할 수 있습니다. 원문 PDF 보기와 로컬 증거 파일까지 대조하는 전체 연구 검사는 별도 자료가 필요합니다.

기준 PDF는 출처 목록에서 정당하게 확보한 동일 파일을 아래 두 위치에 둡니다. 새 교육과정 PDF를 같은 이름으로 덮어쓰지 않습니다.

```text
[별책8] 수학과 교육과정.pdf
site/dist/curriculum.pdf
```

두 위치의 기준 바이트 SHA256:

```text
ba7c7c63ad31ba0fd32e5eb8148d696dd73288acce111495c593298112f8f840
```

근거는 [성취기준 원장](../data/standards.json)과 [출처 목록](../data/sources.json)입니다. 다른 문헌의 확보 범위는 [미확보 원문 목록](미확보원문목록.md), [문헌 주장별 근거](문헌주장별근거.md)를 따릅니다. 내려받기·출처 대조를 완료하지 않은 파일의 확보를 완료로 표시하지 않습니다.

학생 응답이나 수업 관찰을 추가할 때는 개인을 식별할 자료를 공개하지 않습니다. 공개하지 않는 파일을 `.gitignore`에 추가하는 것만으로 이미 기록된 Git 이력에서 제거되지는 않습니다.
