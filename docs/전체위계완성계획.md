# 수학 내용 체계의 미완성 점검과 전체 위계 완성 계획

작성일: 2026년 10월 30일

최종 갱신: 2026년 11월 4일

435개 성취기준의 상세 초안은 모두 작성되어 있다. 다음 목표는 **435개 기준의 하위 목표와 46개 개념군 전체에 대해, 무엇을 먼저 이해해야 하고 어떤 경로로 확장되는지 조건과 근거를 갖추어 작성하는 것**이다. 현재의 관계와 세 시범을 활용하되, 방향 관계가 없는 고교 구간과 학교급 사이의 연결을 우선 보완한다.

1차 완료선은 전체 범위의 **수학적 자체 점검을 마친 위계 설계 초안**이다. 독립 교사·연구자 검토와 학생 반응 검증은 별도 상태로 관리한다. 아래 계획에 따라 목표·과제·조건 원장과 포털을 보강해 왔으며,목표 작성의 범위 충족과 전체 위계 통합의 완료는 구별한다.

## 최신 실행 현황

최신 구조 감사는 [전수 구조 감사](../data/hierarchy_completion_audit.json), 과제·목표별 현황은 [조건과 목표 원장 현황](../data/task_pathway_coverage.json), 상세 이력은 [전체 위계 구현 진행](전체위계구현진행.md)에서 확인한다. 현재 435개 기준·46개 개념군에 2,239개 성취기준 간 관계와 510개 방향 기록이 있다. 방향 미접촉 5개는 분석 범위 안에서 순서를 두지 않는 연결로 판정했다.

초등121개·중학교60개·고등학교254개,전체435개 기준의870개 하위 목표를 작성했다. 고교15개 과목 전체를 포함한다. 명시적 과제는571개(435개 기준)이며 현재 설계570개와 보존한 이전 설계1개를 구별한다. 기존 시범 참조는12개 기준이다. 하위 목표 원장과 과제별 조건이 없는 기준은0개다. 모든 목표 조건의 무순환과7,768개 과제 화면 상태·435개 원본 보존 검사가 통과했다. 방향 기록의 접촉 범위·목표 작성·과제 조건 작성·전체 통합 판정은 별도 지표로 관리한다. 원장 작성은 전체 위계의 완성이나 독립 검증의 완료를 뜻하지 않는다.

성취기준 화면은 학교급 → 학년군·과목 → 영역의 공식 분류로 정리했다. 선택 버튼과 기준 수, 현재 선택 범위, 영역별 원문 펼치기를 제공한다. 이 분류를 학습 선수 순서로 해석하지 않으며, 실제 과제의 조건과 연결은 위계 화면에서 따로 확인한다.

목표별 위계 화면을 추가해 출발 조건→선택 목표→후속 활용을 함께 제공한다. 원장의565개 과제·626개 경로·1,481개 목표 쌍을 사용하고,조건별 적용 목표·전체 AND·대안·학교급 밖 목표를 보존한다. 실제 연결을 따라간 탐색 경로와 화살표 방향을 표시하며 다른 목표에 적용되는 동반 조건을 현재 목표의 선수로 합치지 않는다. 전체870개 목표·네 학교급 범위의3,480개 화면 상태가 통과했다. 기존 첫 화면의 과제별 위계 미검토 안내를 현 원장에 맞추고 전체435개 진입을 목표별 위계와 연결했다.

[목표 연결 감사](../data/goal_network_audit.json)는 목표 원장과 생성 자료의 일치·조건 무순환·기존 방향과의 반대 방향 후보0건·상위 학교급 출발 조건 후보0건을 확인했다. 서로 다른 기준의833쌍·고교 과목 간 조건 적용132건·기초 출발 능력20건을 별도로 집계한다. 이 검사는 의미의 수학적 타당성과 독립 검토를 대신하지 않는다. [1차 완성 보고서](전체위계1차완성보고서.md)에 조건·복합 수행·범위·검토 상태의 전수 대조 결과를 정리했다.1,135개 목표 참조와20개 기초 출발 능력을 점검하고342개 학교급·과목 전환 조건을 별도 표로 남겼다. 독립 검토·학생 검증은 [후속 목록](독립검토와학생검증목록.md)에서 관리한다.

## 전체 위계를 작성하는 단위와 판정 기준

교육과정의 학교급·학년군·과목 위치, 개념의 구성, 의미 확장, 특정 과제의 선수 조건과 수업 순서를 구별한다. 학년이나 코드 번호만으로 화살표를 만들지 않는다. 고교 공통·기본 과목 및 선택과목의 대응 내용도 서로의 필수 선수로 일렬 연결하지 않는다.

각 성취기준을 다음 기록으로 정리한다. 복합 성취기준은 하위 목표에 고유 ID를 부여하고 원래 기준과 대응시킨다.

| 기록 단위 | 필수 내용 |
|---|---|
| 목표 | 공식 문구와 범위, 분해한 목표 수행, 대표 과제, 성공한 설명·풀이 |
| 사고 요소 | 구별하거나 구성할 의미, 필요한 이유, 관찰할 수행, 진단 질문 |
| 위계 주장 | 출발·도착 목표, 관계 종류, 적용 과제·경로·수 범위·표현, 이유와 반례 |
| 조건 묶음 | 함께 필요한 AND 조건, 대체 가능한 OR 경로, 경로별 도착 목표 |
| 근거 | 원문 쪽수 또는 자체 논증, 연구를 쓸 경우 실제 적용 대상과 근거 위치 |
| 판정과 이력 | 작성·자체 점검·독립 검토·학생 검증 상태, 수정 이유, 검토자와 검토 범위 |

하나의 목표로 가는 두 대안 풀이와 정비례·반비례처럼 서로 다른 하위 목표의 분기를 구별한다. 대안이 실질적으로 없는 목표에는 그 이유를 기록하며 형식상 두 경로를 만들지 않는다. 필요한 기초가 현재 교육과정 범위 밖이면 출발 능력으로 명시한다.

관계의 판정 결과는 과제별 필요 조건, 의미 확장, 수업 순서 제안, 순서 없는 연결·대조·병렬, 검토 후 직접 관계를 두지 않음, 근거 부족 보류로 나눈다. 보류는 미완료로 남긴다. 순서가 없다는 판정에는 이유가 있어야 하며, 관련성이 있다는 이유만으로 선수 조건으로 바꾸지 않는다.

## 1차 완료 판정

- **범위:** 435개 기준과 46개 개념군 모두에 목표·내용·관계 판정 기록이 있고, 복합 목표 누락이 없다.
- **내용:** 각 목표의 대표 수행을 실제로 설명할 수 있으며, 필요한 중간 사고·수학적 조건·확인 과제가 있다. 해당 주장에 필요한 원문 문장과 해설·범위를 대조했다.
- **위계:** 선수 조건·확장·교수 제안·순서 없는 관계를 구별했다. 모든 목표의 출발 능력과 도달 경로를 설명하고, 필수 판정에 남은 미검토·보류가 있으면 완료로 표시하지 않는다.
- **조건:** AND 묶음이 빠짐없이 보존되고, 다른 풀이의 OR 경로나 다른 목표의 분기가 합쳐지지 않는다. 대안이 없는 경우에는 검토한 이유가 남아 있다.
- **통합:** 학교급·과목·개념군을 넘는 관계의 양 끝 설명이 일치한다. 순서를 주장하는 관계는 경로별로 순환이 없거나 충돌이 해결되어 있다. 의미 연결의 순환은 오류로 세지 않는다.
- **화면:** 모든 목표에서 기록된 기초·확장과 관계 판정 이유를 확인할 수 있다. 학교급 필터로 조건을 숨기면 전체 조건과 숨김을 구별하고 다시 펼칠 수 있으며, 숨김 상태를 선수 충족으로 표시하지 않는다.
- **검토 이력:** 원장과 생성 결과의 상태가 일치하고 다시 생성해도 이력이 사라지지 않는다. 자동 검사, 자체 수학 점검, 독립 검토, 학생 반응 검증의 수치를 각각 표시한다.

진행률은 상세 문서 수나 화살표 수 대신 `목표 분해 완료 / 내용 보강 완료 / 관계 판정 완료 / 경로 자체 점검 완료 / 독립 검토 / 학생 반응 검증`으로 나누어 집계한다. 학교급·과목·개념군별 남은 항목을 바로 열 수 있게 한다.

## 검사 범위와 실행 출발점

이번 점검에서 최신 소스의 `test_all_concept_pathways.mjs`, `test_school_revision.mjs`, `test_pathways.mjs`는 통과했다. 이 검사는 기존 자료·분류·시범 기능의 일관성을 확인한다. 일반 개념 지도에 세 노드 순환을 넣은 별도 재현에서는 충돌을 감지하지 못했지만, 현재 방향 자료에 그 순환이 있다는 의미는 아니다. 실제 학교급 필터 후의 조건 표시, 검토 상태 보존, 모든 목표의 다단계 경로는 후속 검사에 추가한다.

**전 범위 통합 감사와 탐색 화면 마무리** 결과는 [1차 완성 보고서](전체위계1차완성보고서.md)에 정리했다. 다음 네 항목을 전체435개 기준·870개 목표·46개 개념군의 완료 판정에 적용한다. 재편집 때도 같은 기준을 유지한다.

1. 공식 문구의 복합 수행과 대표 과제·진단·출발 조건이 대응하는지 확인한다. 조건을 교육과정 밖 능력·과제 안 구성·가정으로 나눈 판단도 대조한다.
2. 학교급·과목을 넘는 조건의 양 끝과 적용 목표·범위·판정 이유를 확인한다. 기존 기준 간 관계와 새 과제별 부분 수행의 연결이 어긋나는 항목을 찾아 수정하고 이력을 남긴다.
3. 모든 목표의 출발 경로와 연결을 화면에서 따라갈 수 있는지 점검한다. AND 묶음·동일 목표의 OR·서로 다른 목표의 분기·범위 밖 조건을 보존하고,누적 목표 원장을 실제 탐색에 충분히 드러내는지 확인한다.
4. 관계·목표·경로·화면·생성 결과·검토 상태를 같은 근거로 대조해1차 완성 보고서와 독립 검토 목록을 작성한다. 구조 검사 통과나 작성 수치만으로 완료를 선언하지 않는다.

원자료는 `data/revisions_*.json` 등 기존 보강 원본에 반영하고 생성 결과를 직접 고치는 방식은 피한다. 위계 판정·경로·검토 이력의 새 원장은 해당 원본과 연결한다. 내용 작성과 검토가 누적된 뒤 문서와 포털을 같은 버전으로 생성한다.
