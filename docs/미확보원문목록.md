## 추가로 찾은9판 파일의 누락·중복

[UPI 대학 도서관 저장소](https://elibrary.upi.edu/3739/)는9판2022년·ISBN9780135824146 자료를Full Text로 표시한다. 연결된15,021,647바이트·439쪽 PDF를 확보했으나 검사 결과 전권이 아니다. 앞95쪽이 두 번,뒤83쪽이 세 번 반복돼 있다. 텍스트에서 EBSCO 바닥글과 공백 차이를 제외하고 각 구간이 동일함을 계산 대조했다. 인쇄 쪽71–405가 빠져 있으며 앞부분은 인쇄2–70,뒷부분은406–488이다.

[후보 파일 검사 기록](../data/literature_evidence/DICK_CAREY_2022_candidate_asset_audit.json)에 원격 주소·파일 해시·중복 구간·누락 범위를 남겼다. 최초 검사 당시에는 판본·서지·목차·구간 경계 확인과 텍스트 추출 상태였고 본문 읽기에 따른 새 주장 대응은0건이었다. 이후 목표 분석·총괄평가·부록A–M·용어집/색인을 읽고,도입/요구 분석과 남은 앞부분까지 확인했다. 중복을 제외한 유일178쪽 내용을 모두 확인하고 선정98쪽 이미지를 대조했으며,9판의 별도 주장9건·자체 관찰9건을 대응했다. ## 11월 9일 7판 국제판 본문 전사본 대조

인쇄 ISBN 9781292041254, 표제·저자 세 명과 Pearson Education Limited의 2014년 표기가 일치하는 비공식 HTML 전사본을 확보했다. 원시 HTML은 1,382,505바이트이며 SHA-256은 `ad64b171d9b7d02d6eb0172727c770a6128ac1708afcb334313dd4f53d924bf2`다. 줄바꿈으로 분리된 낱말, 합자, 대소문자를 정규화한 뒤 연속 여덟 단어의 조합을 대조했다. 공식 미리보기 PDF 7~40쪽에서는 18,215개 중 17,108개, Pearson 발췌 PDF 3~8쪽에서는 2,367개 중 2,070개가 전사본에서 확인됐다. 표·도식·단락의 추출 순서는 서로 다를 수 있다. [출판사 판본·목차](https://www.pearson.com/en-gb/subject-catalog/p/systematic-design-of-instruction-the-pearson-new-international-edition/P200000004082?view=educator) · [공식 미리보기](https://api.pageplace.de/preview/DT0400.9781292052663_A24569965/preview-9781292052663_A24569965.pdf) · [Pearson 발췌](https://www.pearson.de/media/muster/ext/9781292052663.pdf)

전사본과 공식 미리보기 PDF 4쪽의 차례 모두 목표 확인이 첫 항목이다. 출판사 상품 목차는 도입 장을 별도로 제시한다. 전사본 본문은 기존 원서 장 번호와 국제판의 연속 쪽 번호를 함께 싣는다. 하위·출발 기능 분석은 원서 4장이고 국제판 차례의 세 번째 항목이며 국제판 46쪽에서 시작한다. 학습자·맥락 분석의 시작은 국제판 78쪽이다. 전사본의 전체 동일성, 누락 여부와 도식의 판면·연결선은 추가 확인이 필요하다.

하위 기능 분석의 국제판 47~61쪽에서 선정 개념과 예를 확인했다. 과제를 실제로 수행하는 하위 절차와 그 절차를 학습하는 데 필요한 기능을 구별한다. 선형 눈금 읽기의 그림 4.3과 4.4 설명은 비슷한 하위 기능도 과제 설명에 따라 달리 배치할 수 있음을 보여 준다. 도식의 상자 번호는 참조 표기다. 출발 기능 경계는 수업 설계 시점의 가정으로 두고, 해당 기능이 없는 학습자에게 출발 지점을 달리 제시하는 사례를 따로 다룬다. 이 내용을 현재 수학 위계에 적용할 때는 특정 풀이의 조건, 대안 풀이, 실제 초기 수행 근거를 분리해 기록한다. 그림 4.3~4.5의 연결선과 누락 여부는 원판을 확보해 대조한다.
