## 핵심 분석 결과

각 설명 경로의 조건·확장·수업 제안만으로 순환이 없는 방향 그래프를 만들고, 간선이 반드시 앞 단계에서 뒤 단계로 향하도록 배치했다. 같은 단계에는 선후를 정하지 않은 항목을 함께 두었다. 단계는 학년이나 학생 능력 수준이 아니다. 수업 제안 간선은 점선으로 구별하며 실제 배치 위치가 모든 학생의 필수 발달 순서라는 뜻은 아니다.

여섯 경로의 대상 참조, AND 묶음, 대안 경로의 격리, 방향별 단계 증가, 순환 입력 거부, 전체 435개 분석 보존을 [회귀 검사](../scripts/test_hierarchy.cjs)로 점검했다. 이 검사는 데이터와 배치의 일관성을 확인하며 교육적 타당성의 독립 심사는 아니다.

## 단위와 분수

3m의 끈을 네 사람에게 같은 길이로 나누고 3÷4=3/4인 이유를 설명한다.

경로: 각 1m를 네 등분, 전체 3m를 네 등분.

대응 기준: 4수01-09, 4수01-10, 6수01-10.

### fraction-01 전체와 기준 단위 구별에서 1m의 1/4 구성로

**과제별 필요 조건** · 각 1m를 네 등분

각 1m에서 얻은 조각의 분모가 어느 단위에 대한 것인지 정해야 한다.

- 성립 조건: 1m별 분배 경로
- 수학적 점검: 1m÷4=1/4m. 전체 3m의 1/4은 3/4m로 서로 다르다.
- 확인 질문: 조각 하나가 전체 3m의 1/4인가?
- 기대 설명: 아니다. 각 1m의 1/4이다.
- 대안과 한계: 전체를 먼저 네 등분하면 이 비교를 나중에 구성할 수 있다.

### fraction-02 같은 길이로 등분에서 1m의 1/4 구성로

**과제별 필요 조건** · 각 1m를 네 등분

단위분수의 분모 4는 같은 크기의 네 부분이라는 조건을 포함한다.

- 성립 조건: 길이를 등분하여 단위분수 구성
- 수학적 점검: 1m의 네 부분 길이가 같을 때만 각 부분을 1/4m라 한다.
- 확인 질문: 조각 네 개의 길이가 다르면 모두 1/4m인가?
- 기대 설명: 네 조각이라는 개수만으로는 충분하지 않다.
- 대안과 한계: 단위분수를 이미 측정할 수 있는 학생에게 물리적 자르기를 반드시 요구하지 않는다.

### fraction-03 1m의 1/4 구성에서 1/4m를 세 번 반복로

**과제별 필요 조건** · 각 1m를 네 등분

각 1m에서 받은 조각이 같은 1/4m임을 유지하며 합친다.

- 성립 조건: 동일한 단위의 세 조각
- 수학적 점검: 1/4+1/4+1/4=3/4.
- 확인 질문: 서로 다른 크기의 전체에서 얻은 1/4도 바로 더할 수 있는가?
- 기대 설명: 측정 단위를 먼저 같게 해야 한다.
- 대안과 한계: 그림의 조각 수만 세는 수행은 길이의 합성을 대신하지 못한다.

### fraction-04 1/4m를 세 번 반복에서 몫을 하나의 수 3/4로 설명로

**과제별 필요 조건** · 각 1m를 네 등분

분배된 몫의 길이를 구성한 뒤 나눗셈 식과 대응한다.

- 대안과 한계: 전체를 먼저 등분하는 경로도 같은 결과를 설명한다.

- 기대 설명: 몫의 개수와 등분 조건을 구별한다.
- 대안과 한계: 각 1m를 먼저 분배할 수도 있다.

### fraction-06 전체와 기준 단위 구별에서 몫을 1m 기준으로 측정로

**과제별 필요 조건** · 전체 3m를 네 등분

전체의 부분 비율을 m 단위 측정값으로 바꾸려면 기준을 조정한다.

- 성립 조건: 전체 먼저 등분한 몫을 m로 이름 붙임
- 수학적 점검: (1/4)×3m=3/4m.
- 확인 질문: 몫을 1/4m라고 하면 왜 맞지 않는가?
- 기대 설명: 1/4은 전체 3m에 대한 비율이기 때문이다.
- 대안과 한계: 공식 조작만으로 답을 낼 수 있어도 두 기준을 구별했는지는 따로 확인한다.

### fraction-07 전체 3m의 1/4 얻기에서 몫을 1m 기준으로 측정로

**과제별 필요 조건** · 전체 3m를 네 등분

얻은 한 몫을 전체 길이와 기준 1m에 각각 대응시킨다.

- 성립 조건: 전체 3m의 1/4인 몫 유지
- 수학적 점검: 같은 한 몫이 전체의 1/4이면서 1m의 3/4다.
- 확인 질문: 전체의 3/4과 1m의 3/4는 같은가?
- 기대 설명: 전자는 9/4m, 후자는 3/4m다.
- 대안과 한계: 전체가 달라지면 같은 분수라도 길이가 달라진다.

### fraction-08 몫을 1m 기준으로 측정에서 몫을 하나의 수 3/4로 설명로

**과제별 필요 조건** · 전체 3m를 네 등분

m로 표현한 한 몫을 수의 몫과 연결한다.

- 성립 조건: 전체 먼저 등분한 경로
- 수학적 점검: 한 명의 길이 3/4m에 대응하는 수가 3÷4의 값이다.
- 확인 질문: 한 사람 몫 네 개를 이으면?
- 기대 설명: 원래 3m로 복원된다.
- 대안과 한계: 단순히 ÷를 분수선으로 바꾸는 규칙과 의미 구성을 구별한다.

### fraction-09 몫을 하나의 수 3/4로 설명에서 1보다 큰 몫으로 확장로

**의미 확장** · 각 1m를 네 등분, 전체 3m를 네 등분

몫을 수로 보는 관점을 1보다 큰 결과에도 적용한다.

- 성립 조건: 양의 정수인 제수; 몫의 크기 제한을 두지 않음
- 수학적 점검: 5÷3=5/3>1. 1/3m를 다섯 번 반복한다.
- 확인 질문: 분수는 언제나 1보다 작은가?
- 기대 설명: 아니다. 기준 단위를 넘어 반복할 수 있다.
- 대안과 한계: 3/4만의 성공으로 가분수 이해를 확정하지 않는다.

### fraction-10 몫을 하나의 수 3/4로 설명에서 역관계로 원래 양 복원로

**수업 순서 제안** · 각 1m를 네 등분, 전체 3m를 네 등분

구성한 몫을 다시 합쳐 보는 검산 활동을 제안한다.

- 성립 조건: 구성 후 점검하는 수업안
- 수학적 점검: 4×3/4m=3m.
- 확인 질문: 나누고 다시 합쳤는데 길이가 달라지면?
- 기대 설명: 누락·겹침·단위 또는 몫의 크기를 확인한다.
- 대안과 한계: 역관계는 처음 문제를 해결하는 도구로도 사용할 수 있다. 유일한 학습 순서가 아니다.

## 비율과 함수

한 쌍의 양의 비교에서 여러 대응쌍의 불변량을 찾고 정비례와 반비례를 구별한다.

경로: 정비례: 비율이 일정, 반비례: 곱이 일정.

대응 기준: 6수02-02, 6수02-03, 9수02-07, 9수02-14, 10공수2-03-04.

### ratio-01 두 양의 역할과 기준 정하기에서 한 쌍의 비율 계산로

**과제별 필요 조건** · 정비례: 비율이 일정

비교 방향과 공통 단위를 정해야 계산한 비율의 의미가 정해진다.

- 성립 조건: 같은 종류 양의 비교; 기준량≠0
- 수학적 점검: 50cm/100cm=1/2. 역방향은 2다.
- 확인 질문: 비교 방향을 바꾸면 같은 비율인가?
- 기대 설명: 일반적으로 역수가 되어 다르다.
- 대안과 한계: 단위가 다른 양의 비는 별도 단위를 갖는 비율로 다룬다.

### ratio-02 한 쌍의 비율 계산에서 y/x의 일정함 확인로

**의미 확장** · 정비례: 비율이 일정

한 쌍의 비율을 여러 대응쌍에서 유지되는 값으로 확장한다.

- 성립 조건: 정비례 부분에 한정; x≠0에서 비 계산
- 수학적 점검: y=500x이면 모든 x≠0에서 y/x=500.
- 확인 질문: 한 쌍에서 500이면 정비례인가?
- 기대 설명: 다른 대응과 전체 규칙도 확인해야 한다.
- 대안과 한계: 반비례의 불변량은 비율이 아니라 곱이다.

### ratio-03 여러 대응쌍과 변화 읽기에서 y/x의 일정함 확인로

**과제별 필요 조건** · 정비례: 비율이 일정

관계의 불변량은 두 양의 대응을 바꾸며 검사한다.

- 성립 조건: 대응 규칙 또는 일반적 관계 확인
- 수학적 점검: y=x+2에서 x=1,2이면 비는 3,2로 다르다.
- 확인 질문: 증가하는 그래프이면 정비례인가?
- 기대 설명: 증가와 일정한 비율은 다르다.
- 대안과 한계: 몇 점의 일치는 관찰한 표의 성질일 뿐 전체 법칙을 보장하지 않는다.

### ratio-04 y/x의 일정함 확인에서 불변량으로 관계 설명로

**과제별 필요 조건** · 정비례: 비율이 일정

이 경로에서는 일정한 비율을 관계의 식과 의미로 설명한다.

- 성립 조건: 전체 규칙 y=kx 확인
- 수학적 점검: x≠0의 비율 k와 식 y=kx를 대응시킨다.
- 확인 질문: x=0에서도 y/x를 계산하는가?
- 기대 설명: 계산할 수 없지만 식이 정한 y=0은 따로 해석한다.
- 대안과 한계: 정비례 식에는 k=0인 경우도 있으며 상황의 범위를 명시한다.

### ratio-05 두 양의 역할과 기준 정하기에서 xy의 일정함 확인로

**과제별 필요 조건** · 반비례: 곱이 일정

두 양이 무엇인지와 고정한 전체량을 정한다.

- 성립 조건: 양의 두 변 길이; 직사각형 넓이 12 고정
- 수학적 점검: 3×4=12, 6×2=12.
- 확인 질문: 한 변이 1 늘면 다른 변도 1 줄어드는가?
- 기대 설명: 곱 12를 유지하도록 정해야 한다.
- 대안과 한계: 모든 반비례가 넓이 상황인 것은 아니다.

### ratio-06 여러 대응쌍과 변화 읽기에서 xy의 일정함 확인로

**과제별 필요 조건** · 반비례: 곱이 일정

여러 대응쌍에서 고정량을 확인한다.

- 성립 조건: 고정된 넓이의 관계
- 수학적 점검: x가 t배이면 y는 1/t배가 되어 곱이 같다.
- 확인 질문: 2×6과 3×4의 비율도 같은가?
- 기대 설명: 곱은 같지만 y/x는 다르다.
- 대안과 한계: 표의 몇 점만으로 전체 함수식을 확정하지 않는다.

### ratio-07 xy의 일정함 확인에서 불변량으로 관계 설명로

**과제별 필요 조건** · 반비례: 곱이 일정

고정된 곱을 두 양의 관계로 설명한다.

- 성립 조건: xy=12; x>0인 길이 맥락
- 수학적 점검: xy=12에서 y=12/x.
- 확인 질문: 반비례는 합이 일정한 관계인가?
- 기대 설명: 이 과제에서는 두 양의 곱이 일정하다.
- 대안과 한계: x+y=12인 관계와 구별한다.

### ratio-08 불변량으로 관계 설명에서 표·식·그래프를 대응로

**수업 순서 제안** · 정비례: 비율이 일정, 반비례: 곱이 일정

불변량의 설명을 표·식·그래프로 비교하는 수업 순서를 제안한다.

- 성립 조건: 선택한 불변량 보존
- 수학적 점검: 표의 대응쌍 (x,y)를 같은 좌표의 점으로 옮긴다.
- 확인 질문: 표의 행 번호가 x좌표인가?
- 기대 설명: x열의 실제 값과 행 번호를 구별한다.
- 대안과 한계: 그래프에서 시작해 불변량을 찾는 역방향 수업도 가능하다.

### ratio-09 표·식·그래프를 대응에서 함수와 정의역 해석로

**의미 확장** · 정비례: 비율이 일정, 반비례: 곱이 일정

대응을 표현하는 활동에서 입력 범위와 함숫값을 명시하는 관점으로 넓힌다.

- 성립 조건: 선택한 대응 규칙; 맥락과 수학적 정의역 구별
- 수학적 점검: 양의 길이는 x>0이나 함수 12/x는 실수 x≠0에서도 정의할 수 있다.
- 확인 질문: 표에 없는 입력은 자동으로 불가능한가?
- 기대 설명: 정의역은 문제와 규칙으로 정한다.
- 대안과 한계: 함수 개념을 먼저 소개하는 수업도 가능하며 발달의 필수 순서를 주장하지 않는다.

### ratio-10 함수와 정의역 해석에서 반비례에서 유리함수로로

**의미 확장** · 반비례: 곱이 일정

역수항과 정의역을 이동된 유리함수에 적용한다.

- 성립 조건: 문자식 변형 추가; 분모 0 제외; 퇴화 경우 별도
- 수학적 점검: (2x+1)/(x-1)=2+3/(x-1), x≠1.
- 확인 질문: 약분하거나 식을 변형하면 제외값이 복원되는가?
- 기대 설명: 원래 함수의 정의역은 별도로 유지한다.
- 대안과 한계: 초등 비율만으로 유리함수 학습이 충분하지 않으며 문자식·좌표·함수가 추가된다.

## 넓이와 도형

단위넓이와 변형 전후의 관계로 평행사변형·삼각형의 넓이를 설명한다.

경로: 잘라 옮겨 설명, 합동 도형을 복제해 설명.

대응 기준: 4수03-12, 6수03-12, 6수03-13, 6수03-14.

### area-01 같은 단위넓이로 덮기에서 직사각형의 배열과 곱로

**과제별 필요 조건** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

배열의 곱으로 넓이를 해석하려면 같은 단위로 센다는 의미가 필요하다.

- 성립 조건: 같은 단위 정사각형으로 빈틈 없이 덮기
- 수학적 점검: 6×4=24개의 1cm²가 24cm²를 이룬다.
- 확인 질문: 6cm×4cm의 답이 24cm인가?
- 기대 설명: 결과는 단위넓이를 센 24cm²다.
- 대안과 한계: 구체물 덮기를 매번 실제로 수행해야 한다는 뜻은 아니다.

### area-02 직사각형의 배열과 곱에서 평행사변형을 직사각형으로로

**과제별 필요 조건** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

변형한 직사각형의 배열 구조로 넓이를 구한다.

- 성립 조건: 밑변과 높이를 보존하는 변형
- 수학적 점검: 가로 b, 세로 h인 직사각형의 넓이는 bh.
- 확인 질문: 변형 후 가로와 세로를 무엇으로 읽는가?
- 기대 설명: 원래의 밑변과 수직 높이에 대응한다.
- 대안과 한계: 다른 넓이 분해 전략도 가능하며 공식 암기를 선수로 강제하지 않는다.

### area-03 조각 손실·겹침 추적에서 평행사변형을 직사각형으로로

**과제별 필요 조건** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

자르기 전후 조각의 대응을 추적해야 같은 넓이라고 설명할 수 있다.

- 성립 조건: 재배치 경로; 조각의 손실·겹침 없음
- 수학적 점검: 부분들의 넓이 합을 바꾸지 않는 재배치는 전체 넓이를 보존한다.
- 확인 질문: 겹쳐 붙이면 덮인 영역도 같은 넓이인가?
- 기대 설명: 겹친 만큼 영역의 합과 실제 덮기가 달라진다.
- 대안과 한계: 보존 과제를 사전에 통과해야 모든 넓이를 배운다는 주장은 아니다.

### area-04 밑변과 수직 높이 대응에서 평행사변형을 직사각형으로로

**과제별 필요 조건** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

직사각형의 세로에 대응하는 수직 거리를 정한다.

- 성립 조건: 선택한 밑변과 그 수직 높이
- 수학적 점검: b=6,h=4,옆변=5이면 넓이는 24이지 30이 아니다.
- 확인 질문: 밑변을 바꾸면 높이도 바꾸는가?
- 기대 설명: 선택한 밑변에 대응하는 수직 거리를 다시 잡는다.
- 대안과 한계: 대각선 길이만 쓰는 별도 경로에 같은 길이 선정을 강제하지 않는다.

### area-05 조각 손실·겹침 추적에서 삼각형 넓이를 변형으로 설명로

**과제별 필요 조건** · 잘라 옮겨 설명

삼각형을 적절히 잘라 직사각형으로 옮긴 경로에서 넓이 보존을 사용한다.

- 성립 조건: 중점 등을 이용한 적절한 분할; 새 직사각형의 변 길이 설명
- 수학적 점검: 밑변 b,높이 h인 삼각형을 재구성한 직사각형은 예를 들어 b와 h/2를 변으로 갖는다.
- 확인 질문: 새 직사각형이 언제나 b×h인가?
- 기대 설명: 한 변의 절반 관계를 확인해야 한다.
- 대안과 한계: 합동 복제 경로는 보존뿐 아니라 두 배 관계도 추적한다.

### area-06 직사각형의 배열과 곱에서 삼각형 넓이를 변형으로 설명로

**과제별 필요 조건** · 잘라 옮겨 설명

재구성한 직사각형의 넓이를 계산해 원래와 대응한다.

- 성립 조건: 적절한 분할·이동 경로
- 수학적 점검: b×(h/2)=bh/2.
- 확인 질문: 높이가 절반이면 왜 식에 2로 나누기가 생기는가?
- 기대 설명: 새 도형의 변 길이 관계를 나타낸다.
- 대안과 한계: 복제한 두 개를 되돌려 2로 나누는 다른 설명도 있다.

### area-07 밑변과 수직 높이 대응에서 삼각형 넓이를 변형으로 설명로

**과제별 필요 조건** · 잘라 옮겨 설명

분할 경로에서도 원래 삼각형의 밑변과 수직 높이를 대응해야 한다.

- 성립 조건: 선택한 분할 구성의 높이 관계 확인
- 수학적 점검: b=6,h=4이면 6×2=12.
- 확인 질문: 회전시키면 종이의 세로가 높이인가?
- 기대 설명: 밑변과의 수직 관계를 유지한다.
- 대안과 한계: 특정 한 그림의 자르기를 모든 삼각형의 유일한 구성으로 제시하지 않는다.

### area-08 합동 삼각형 두 개 붙이기에서 두 배에서 원래 한 개로로

**과제별 필요 조건** · 합동 도형을 복제해 설명

합동인 두 도형의 넓이 합과 한 개의 넓이 사이에 두 배 관계가 있다.

- 성립 조건: 합동인 두 개; 내부 겹침 없음
- 수학적 점검: 같은 넓이 S 두 개의 합은 2S.
- 확인 질문: 서로 다른 삼각형 두 개도 합의 절반이 각각의 넓이인가?
- 기대 설명: 합동 또는 넓이가 같다는 조건이 필요하다.
- 대안과 한계: 분할·이동 경로에서는 이 복제 행동을 요구하지 않는다.

### area-09 평행사변형을 직사각형으로에서 삼각형 넓이를 변형으로 설명로

**과제별 필요 조건** · 합동 도형을 복제해 설명

두 합동 삼각형으로 만든 평행사변형의 넓이를 이용한다.

- 성립 조건: 복제로 같은 b,h인 평행사변형 구성
- 수학적 점검: 평행사변형 넓이 bh는 두 삼각형 넓이의 합이다.
- 확인 질문: 새 도형의 높이가 원래 높이의 두 배인가?
- 기대 설명: 이 구성에서는 높이가 같고 넓이가 두 배다.
- 대안과 한계: 직사각형으로 직접 재구성하면 평행사변형 공식을 거치지 않을 수 있다.

### area-10 두 배에서 원래 한 개로에서 삼각형 넓이를 변형으로 설명로

**과제별 필요 조건** · 합동 도형을 복제해 설명

합친 넓이에서 원래 한 도형의 넓이로 돌아온다.

- 성립 조건: 합동 복제 경로
- 수학적 점검: 2S=bh에서 S=bh/2.
- 확인 질문: 삼각형이라는 이름 때문에 항상 2로 나누는가?
- 기대 설명: 복제 구성에서 두 개를 먼저 계산했기 때문이다.
- 대안과 한계: 다른 분할 경로에서는 변 길이의 절반으로 같은 식을 설명한다.

### area-11 삼각형 넓이를 변형으로 설명에서 사다리꼴의 두 경로 비교로

**의미 확장** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

두 삼각형으로 나눈 넓이를 더하는 경로를 사다리꼴에 적용한다.

- 성립 조건: 평행한 두 밑변 a,b와 공통 높이 h; 분할 경로
- 수학적 점검: ah/2+bh/2=(a+b)h/2.
- 확인 질문: 사다리꼴을 배우려면 삼각형 공식을 반드시 먼저 외워야 하는가?
- 기대 설명: 복제해서 평행사변형을 만드는 다른 경로도 가능하다.
- 대안과 한계: 이 선은 두 삼각형 분할 경로에 한정되며 복제 경로의 필수 선행 조건은 아니다.

### area-12 삼각형 넓이를 변형으로 설명에서 마름모의 다른 길이 정보로

**의미 확장** · 잘라 옮겨 설명, 합동 도형을 복제해 설명

수직인 대각선으로 나눈 삼각형의 합으로 마름모 넓이를 설명할 수 있다.

- 성립 조건: 대각선의 수직·이등분 성질; 삼각형 분해 경로
- 수학적 점검: 네 부분을 합하면 d1×d2/2. 대각선 6,4이면 12.
- 확인 질문: 임의 사각형에도 대각선 곱의 절반을 쓰는가?
- 기대 설명: 3×4 직사각형은 대각선 5이므로 12.5가 되어 실제 12와 다르다.
- 대안과 한계: 밑변×높이 경로는 대각선 성질을 먼저 요구하지 않는다.
