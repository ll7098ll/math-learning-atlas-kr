# 포털 페이지 트리 점검과 최적화 계획

2026년 11월 26일(KST) 기준, 학교급에서 출발해 성취기준 435개 모두에 도달했다. 우선 고칠 곳은 세 군데다. **초·중 전체 연결망에는 고교까지 표시되고, 학교급별 목록에서 ‘전체로 돌아가기’를 눌러도 초등 필터가 남고, 지도 보기를 바꾸면 방금 고른 기준이 사라진다.** 세 현상 모두 GitHub Pages와 Sites에서 재현했다. 다섯 상단 메뉴를 유지하면서 화면을 건널 때 전달하는 학교급·기준 코드와 복귀 위치부터 고치는 순서를 제안한다.

2026년 11월 26일 로컬 스냅샷에 아래 네 단계의 변경을 반영했다. 지도 범위 및 중심, 개요와 목록 복귀, 예전 주소 이동, 출처 파일을 다시 검증했다. 아래 재현 기록은 수정 전 기준이며, 구현과 재검사 결과는 검증 문서에 있다. [탐색 경로 재검사](VERIFICATION.md#2026년-11월-26일-포털-탐색-경로-정비)

같은 날 기준별 관계 파일 435개도 공통 출처 파일을 쓰도록 바꿨다. 새 스냅샷과 이전 형식을 대조해 관계 기록과 출처 표시를 확인했다. [출처 공유 검증](VERIFICATION.md#2026년-11월-26일-기준별-관계-파일의-출처-공유)

### 공유 주소로 들어오는 길

주소는 각 사이트의 포털 루트를 기준으로 읽는다. `code`, `target`, `node`는 각 화면이 선택한 기준을 전달하는 값이다.

| 화면 | 주요 주소 또는 상태 |
|---|---|
| 홈·개요·결과·공식 내용 체계 | `#view=catalog`에서 `stage=overview`는 개요, `list=1`은 전체 목록, `tab=structure`는 공식 내용 체계다. `scope/band/domain/q/page`로 선택을 전달한다. |
| 기준 요약·원고 | `#view=standard&code=6수01-10`에서 `panel`은 요약 안의 위치다. `section=task`처럼 원고의 절을 지정한 기존 루트 주소는 `legacy.html`의 해당 절을 연다. |
| 두 범위 비교 | `#view=compare`에 `left/right`, 각 영역·기준 코드를 더한다. |
| 지도·관계 근거 | `legacy.html#view=network`에서 `node`는 중심 기준, `mapMode=full`은 전체 연결망이다. `view=connections`는 `code/relation`으로 개별 관계를 연다. |
| 개념 흐름·학교급별 구조 | `legacy.html#view=overview&mode=flow` 또는 `mode=structure`. 구조를 펼친 상태는 `density=expanded`다. |
| 개념·목표·과제·시범 지도 | `legacy.html#view=hierarchy`에서 `concept=fraction`은 개념군, `map=fraction`은 시범 지도다. `mode=goals/tasks`는 각각 `target` 기준의 목표와 과제를 연다. `goal/taskCase/taskRoute`가 구체적인 선택을 가리킨다. |
| 자료 안내·독립 도구 | `legacy.html#view=about`, `distribution-lab.html`의 `df/mode/range` 쿼리와 절 앵커, `inquiry-workbook.html#workbook-part-2` 같은 장 주소가 있다. |
| 예전 진입점 | `legacy.html#view=catalog`와 `legacy.html#view=map`은 구 목록을 직접 연다. `view=explore`는 `connections`의 별칭이다. Sites에서는 세 하위 HTML 주소가 확장자 없는 주소로 이동하며, Pages는 프로젝트 하위 경로와 확장자를 사용한다. |

## 확인한 문제

| 우선순위 | 재현 경로와 관찰 | 사용자에게 미치는 영향 |
|---|---|---|
| 1 · 학교급 범위 | 홈의 ‘두 기준이 이어지는 이유’ → 분수 예시 → ‘다른 방식으로 연결 보기’ → ‘전체 연결망’. 주소는 `scope=em`인데 435개 점이 나온다. `scope=mh`로 직접 열어도 435개다. 두 공개본에서 확인했다. | 초·중은 181개, 중·고는 314개다. 선택 범위 밖 기준과 관계까지 그려져 학교급 비교 결과를 잘못 읽을 수 있다. |
| 1 · ‘전체로 돌아가기’ | 학교급별 성취기준에서 초등 121개로 좁힌 뒤 ‘전체로 돌아가기’를 누른다. 두 공개본 모두 링크가 `scope=e`를 다시 붙여 초등 한 열, 121개가 그대로 남았다. | ‘전체’로 표시된 버튼으로 세 학교급을 다시 볼 수 없다. |
| 1 · 지도 중심 | 전체 지도에서 `9수01-03`을 선택 → ‘학년·개념으로 연결 따라가기’. 두 공개본에서 주소의 `node`가 사라지고 `6수01-10` 분수 예시가 열렸다. 로컬에서 한 기준으로 직행한 뒤 이웃을 고르면 전환 링크가 최초 기준을 다시 열기도 했다. | 현재 보던 기준을 다시 찾아야 한다. ‘435개 기준 전체 지도 보기’처럼 범위를 의도적으로 넓히는 동작에서도 선택 점은 별도로 유지할 수 있다. |
| 2 · 상위 위치 | 영역 목록과 기준 상세에서 각각 ‘초등학교’를 누른다. 목록에서는 학년군을 고르는 개요, 상세에서는 초등 121개 전체 목록이 열린다. 학년군 링크도 개요와 결과로 갈린다. | 같은 이름의 상위 링크로 한 단계 올라가도 출발 화면에 따라 다른 일을 해야 한다. 중학교는 홈에서 단일 학년군으로 바로 진입하지만 상위 링크를 따라가면 다시 고르는 경로가 있다. |
| 2 · 비교 후 복귀 | ‘분수’ 검색 결과에서 본문의 비교 링크와 상단 메뉴의 비교 링크를 각각 이용한다. 두 공개본에서 ‘교육과정 탐색으로’를 누르면 본문 경로는 분수 결과를 복원하고, 상단 경로는 검색어가 없는 홈을 연다. | 같은 이름의 복귀 버튼으로 검색을 이어갈 수 있는지가 달라진다. 검색 → 상세 → 브라우저 뒤로가기는 로컬 대표 사례에서 정상 복귀했다. |
| 2 · 화면과 현재 위치 | `legacy.html#view=overview`는 학교급별 구조를 보여주면서 위치와 선택 탭을 ‘개념 흐름’으로 표시한다. `mode=flow`를 명시하면 실제 개념 흐름이 열린다. 두 공개본에서 확인했다. 로컬의 `legacy.html` 첫 진입에서는 본문이 연결 지도인데 상단 ‘개념으로 보기’가 선택됐다. | 주소, 제목, 선택 메뉴 중 무엇을 기준으로 삼느냐에 따라 다른 화면으로 이해할 수 있다. |
| 2 · 예전 주소와 오류 복구 | 로컬에서 구 목록은 현행 탐색과 별도 화면으로 남는다. 존재하지 않는 `map` 값은 분수 시범 지도로 바뀌고, 존재하지 않는 `concept`의 안내는 개념을 다시 고르라고 하지만 복구 버튼은 ‘전체 조망’으로 간다. | 오래된 공유 링크를 연 사람이 잘못된 예시를 원래 자료로 받아들이거나 다른 메뉴에서 다시 찾아야 한다. |
| 3 · 자료 안내 첫 로딩 | 새 브라우저 세션에서 자료 안내를 열면 두 공개본 모두 출처 표시를 위해 `connections.json` 13,545,654바이트를 읽는다. 카탈로그 392,677바이트는 별도다. | 탐구 도구로 가려는 사람도 관계 전체 파일 처리를 기다린다. 수치는 압축 해제 후 크기이며 대기 시간은 측정하지 않았다. |

전체망은 `e/m/h`만 처리하고, 공통 자료 모델은 `em/mh`도 지원한다. 학교급별 구조의 ‘전체로 돌아가기’는 범위 값을 생략해서 링크 생성기가 기존 범위를 다시 붙인다. 중심 이동은 주소를 갱신하지만 보기 전환 링크는 최초 선택으로 만들어진다. 목록과 상세도 서로 다른 코드에서 상위 링크를 조립한다. ## 권장 구조와 적용 순서

상단에는 현재의 다섯 입구를 둔다. **교육과정 탐색**에서 학교급·학년군은 언제나 개요를 열고, 전체 목록은 ‘이 범위의 성취기준 전체’로 구별한다. **연결 지도**에서 ‘주변 기준 보기’와 ‘전체 연결망’은 같은 중심을 공유한다. **개념으로 보기**에서는 개념군과 시범 지도를 구별하고, 목표·과제를 열면 해당 기준과 목표를 위치에 표시한다. **비교**는 진입한 검색·기준으로 돌아가는 경로를 제공하고, **자료 안내**에서 두 탐구 도구는 한 번의 선택으로 바로 연다.

| 순서 | 구현할 변경 | 완료 판단 |
|---|---|---|
| 1. 학교급 전환과 지도 중심 수정 | 전체망·주변 지도에 같은 학교급 판정을 적용한다. 학교급별 구조의 ‘전체로 돌아가기’는 `scope=all`을 명시한다. 중심이 바뀔 때 주소, 선택 표시, 보기 전환 링크를 함께 갱신한다. | 전체망의 전체·초·중·고·초중·중고 점 수가 **435·121·60·254·181·314**와 일치하고 각 선의 양 끝도 범위에 속한다. 학교급별 구조에서 초등 → 전체로 돌아가면 435개·세 열이 보인다. A → 이웃 B → 보기 전환 → 새로고침에서 B의 코드·표시·상세 링크가 일치한다. |
| 2. 위치와 복귀 통일 | 학교급·학년군 개요, 영역 목록, 상세의 대표 주소를 한 곳에서 만든다. 검색에서 비교로 가는 두 입구가 출발 목록의 조건과 초점을 기록하게 한다. 처음부터 비교로 직행한 경우에는 탐색 홈을 명시한다. | 목록·상세에서 같은 상위 라벨을 누르면 같은 주소·제목에 도달한다. ‘분수’ 검색의 상단·본문 양쪽에서 돌아올 때 검색어·범위·페이지·출발 링크 초점이 복원된다. 두 번째 목록 페이지에서도 확인한다. |
