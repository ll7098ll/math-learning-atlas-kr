# 성취기준과 사고 과정의 분석 규칙

성취기준, 세부 사고, 과제 수행, 학습 경로를 서로 다른 대상으로 기록한다. 하나의 정답이나 계산 절차만으로 학생의 이해를 확정하지 않고 설명, 표상, 조건 변화에 대한 반응을 함께 살핀다.

## 목표 분석과 세부 사고 분석

목표 분석에서는 최종 수행과 그 수행을 구성하는 주요 단계를 정한다. 하위요소 분석에서는 각 단계를 가능하게 하는 개념, 구별, 규칙, 표현 능력과 출발점 능력을 찾는다. 여기에 수학 개념 분석과 학습 경로 연구를 더해 실제 학습에서 구성할 의미를 밝힌다.

딕앤 캐리 원전의 목표 분석과 하위 및 출발점 기능 분석이라는 구분은 출판사 목차에서 확인했다. 세부 기법의 엄밀한 적용은 원전 정독 후 보완한다. 아래의 관계 체계와 작성 양식은 이 연구의 설계 규칙이다. [출판사 자료](https://www.pearson.com/en-gb/subject-catalog/p/systematic-design-of-instruction-the-pearson-new-international-edition/P200000004082?view=educator)

학생의 사고는 관찰된 말, 그림, 조작을 해석하여 추론한다. 모든 학생에게 같은 순서로 일어나는 내적 과정이라고 단정하지 않는다.

## 분석 단위

| 대상 | 기록 내용 | 예 |
|---|---|---|
| 성취기준 | 공식 코드, 원문, 범위, 적용 시 고려 사항 | 6수01-10 |
| 개념과 사고 요소 | 학생이 구별하거나 구성하는 의미 | 전체 3m와 기준 단위 1m를 구별하기 |
| 수행 단계 | 특정 과제에서 하는 선택과 행동 | 각 1m를 네 등분하고 한 조각씩 분배하기 |
| 진단 과제 | 이해를 구별할 상황과 질문, 판단 근거 | 같은 몫을 전체의 1/4과 1m의 3/4로 설명하기 |
| 교수 활동 | 변화를 돕기 위해 제안하는 경험과 발문 | 1m 끈과 3m 끈에서 같은 길이를 표시하기 |
| 연결 관계 | 두 대상 사이의 관계, 조건, 근거 | 기준량의 재설정이 분수와 비율을 잇는 방식 |

세부요소는 독립된 진단, 지도, 전이의 차이를 만드는 수준까지 나눈다. 차이가 없는 문장을 계속 쪼개거나 모든 행동을 선수 능력으로 만들지 않는다. 개념을 명사로만 적지 않고 학생이 무엇을 식별하고 구성하는지 동사로 쓴다.

## 연결 유형

| 데이터 값 | 의미 | 방향과 주의점 |
|---|---|---|
| has_subskill | 목표를 구성하는 사고와 수행의 하위요소 | 성취기준에서 요소로. 목표의 분해이며 학습의 필수 선후 순서를 뜻하지 않음 |
| requires_for_task | 명시한 과제나 경로에서 필요한 조건 | 선수 요소에서 목표로. 조건과 다른 경로를 기록 |
| meaning_connection | 같은 양 또는 관계를 다른 의미에서 설명 | 학습 순서를 뜻하지 않음 |
| representation_translation | 상황, 그림, 수직선, 표, 식 사이의 대응 | 표상을 바꾸며 보존되는 의미와 새로 필요한 해석을 기록 |
| generalizes | 범위, 대상, 조건을 넓혀 기존 의미를 재구성 | 원래 개념에서 확장된 개념으로. 추가 학습을 명시 |
| contrasts | 혼동하기 쉬운 개념이나 조건의 차이 | 비교 대상의 순서는 선수 관계를 뜻하지 않음 |
| instructional_sequence | 설계한 수업에서 선택한 순서 | 그 순서가 유일한 학습 순서라는 주장을 포함하지 않음 |
| supports_learning | 연구가 특정 학습 지원 관계를 뒷받침 | 대상, 방법, 범위가 확인된 연구가 필요 |

두 선수를 모두 요구하면 AND, 어느 한 경로로 충분하면 OR로 적는다. 요구 조건이 특정 표현이나 풀이에만 해당하면 그 경로를 한정한다. 학교에서 먼저 배우는 사실만으로 requires_for_task를 만들지 않는다.

## 근거의 구분

관계마다 다음 항목을 따로 기록한다. 이 분류는 연구 질의 서열이 아니라 서로 다른 질문에 대한 근거의 종류다.

- 교육과정 명시: 원문이 실제로 요구하는 내용과 위치.
- 수학적 논증: 정의, 관계식, 불변량, 구성, 반례를 통한 설명.
- 인지적 가설: 학생이 해당 방식으로 의미를 구성할 수 있다는 분석.
- 학습 연구: 연구 대상과 과제에서 관찰되거나 검토된 사고.
- 교수 제안: 학습 경험과 발문에 대한 설계.

출처가 연결을 직접 주장하는지, 여기서 가져온 아이디어를 적용한 것인지도 구별한다. 한 문헌을 인용했다는 이유로 자체 제작한 진단 과제의 정확도나 교수 효과까지 입증됐다고 쓰지 않는다.

## 표현과 진단

표현 전환에서는 그림에서 식을 읽기와 식에서 그림을 만들기를 모두 확인한다. 수직선은 점뿐 아니라 0, 단위 길이, 간격의 의미를 확인한다. 표에서는 한 행의 값과 두 양의 대응 관계를 구별한다.

진단 과제는 쉬운 계산, 비정형 조건, 표상 전환, 반례나 오류 설명 중 필요한 것을 조합한다. 읽기나 그림 그리기의 어려움이 수학 개념의 어려움과 섞일 경우 조작물이나 구두 질문으로 추가 확인한다. 단일 오답에서 원인을 하나로 확정하지 않는다.

태도와 메타인지는 별도 관찰 항목으로 둔다. 이유를 찾으려는 시도, 다른 전략 비교, 답의 타당성 점검을 살피되 계산 성공 여부로 태도를 판단하지 않는다.

## 학교급 내부와 학교급 간 연결의 작성 조건

각 연결에 초등의 출발 의미, 중간 개념, 후속 성취기준, 추가 사고, 성립 조건을 적는다. 예를 들어 비율에서 미분계수로 연결할 때는 두 양의 비, 변화량의 비, 함수, 극한을 건너뛰지 않는다. 중고등 314개도 독립적인 상세 분석의 대상이며 초등 연결을 설명하는 데 필요한 일부 개념만으로 범위를 제한하지 않는다.

고등학교의 과목은 분기 구조로 취급한다. 연결의 부재가 검토 결과일 수 있으며 모든 초등 개념을 미적분으로 연결하는 것을 목표로 하지 않는다.

연결 데이터의 `intermediate_standards`는 직접 선수로 해석하면 안 되는 연결에서 점검할 중간 개념의 코드다. 목록이 완전한 학습 사슬을 뜻하지 않으며 해당 문서의 조건과 추가 학습 설명을 함께 읽는다. 기본수학과 공통수학의 공유 논증 참조는 평행한 목표의 비교이며 이수 순서가 아니다.

## 상태와 수정

| 상태 | 의미 |
|---|---|
| 미착수 | 성취기준 목록만 존재 |
| 초안 | 상세 분석 양식의 주요 내용과 예제가 작성됨 |
| 검토 완료 | 수학, 원문, 문헌, 대안 경로와 진단 내용을 검토함 |
| 학생 반응 검증 | 실제 반응 자료에 근거해 해석과 과제를 수정함 |

원문 대조 상태는 상세 분석 상태와 별도로 관리한다. 수정 시 변경 이유와 영향을 받는 세부요소 및 연결을 기록한다.

## 개별 보강과 공통 출력

전체 상세 분석은 [공통 분석 양식](성취기준분석양식.md)의 12개 절을 따른다. 개별 보강 원고는 `data/revisions_*.json`에 저장하고, 기존 세 사례는 `data/initial_case_studies.json`에서 내용을 보존한다. 과제별 조건과 풀이를 개별 작성하고 사고 요소의 첫 두 개를 자동으로 AND 묶음으로 만들지 않는다.

새 내부 관계는 원래 관계 ID와 분리하여 식별하고 출발·도착·적용 범위·이유·조건·확인 질문을 함께 기록한다. 후보 관계에는 방향을 부여하지 않으며, 수학적으로 자체 점검한 의미 확장과 과제별 필요 조건만 해당 보기의 상대 배치에 사용한다. 학교급 필터는 양 끝이 모두 범위 안인 관계만 표시한다.

독립 검토와 학생 반응 검증을 수행하기 전에는 해당 상태로 승격하지 않는다. 자체 계산·정의·반례 점검과 학습 효과의 실증 검증을 구별한다.
