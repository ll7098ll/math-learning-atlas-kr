# 수학 성취기준 전체 위계 1차 완성 보고서

2026년11월4일. [전체 위계 완성 계획](전체위계완성계획.md)의1차 완료선은 **435개 성취기준 전체를 대상으로 수학적 자체 점검을 마친 위계 설계 초안을 제공하는 것**이다. 작성자는 Codex다. 교사·연구자의 독립 검토와 실제 학생 반응 검증은 다음 단계로 구별한다.

## 제공하는 전체 범위

초등121개·중학교60개·고등학교15과목254개를 합한435개 기준,46개 개념군과870개 하위 목표를 포함한다. 모든 하위 목표에 공식 문구·범위·확인할 수행·대표 과제와진단이 있다. 목표 원장은565개 과제·626개 설명 경로·1,481개 고유 목표 쌍을 제공한다. 기존 과제를 포함한 과제 화면은571개 중현재570개와 보존한 이전1개를 구별한다.

각 목표에서 과제에 쓰이는 출발 조건,그 조건을 요구하는 이유,같은 목표의 대안,해당 수행을 활용하는 후속 목표를 읽고 이동할 수 있다. 공식 학년군·과목·영역은 위치 분류이며 학습 선수 화살표와 구별한다. 성취기준 찾기는 이 위치를 선택하는 입구다.

## 통합 감사에서 고친 내용

- 삼각함수 덧셈정리와이차곡선의 거리식은 내분 목표 전체 대신 좌표 읽기·피타고라스의 실제 부분 수행과연결하고,거리식 구성은 과제 안에서 확인한다.
- 공통·기본수학2의 배수 명제는 이상·이하 목표 대신 배수 목표를 참조한다. 자연수에서 정수 전체로 넓히는 단계는 과제 안에 명시했다.
- 회전체는 원기둥·원뿔·구의 해당 목표를 각각 참조한다. 부피는 블록 개수 일반 대신 부피 단위와직육면체 부피 원리에 연결한다.
- 피타고라스의 닮음 설명에서 부분 길이의 합을 평행선의 비 정리 선수로 두지 않는다. 접선 과제의 직각 조건도 실제 수직 목표를 사용한다.
- 정수·일차식·다항식의 합과차는 수행별로 조건과 적용 목표를 나누었다. 평행사변형 목표에는 실제로 정당화하는 대변 성질을 드러냈다.
- 일반 함수의 정의역·치역과역대응의 일대일대응 조건을 구별했다. 역함수의 조건은 해당 과제에서 확인한다.
- 개념군 관계 화면의 일괄 ‘선수 위계 미검토’를 실제 관계별 상태·검토 이유·날짜·검토 범위 표시로 바꾸었다. 목표·과제 자체 점검과기존 연결의 검토 상태도 구별했다.

## 검토 범위와 후속 단계

목표·과제 원장435개 기준의 자체 점검,기존 의미 연결의 위계 검토,독립 검토,학생 반응 검증은 별도 지표다. 기존 기준 간 관계2,239개 중위계 검토 원장에 자체 점검이 기록된 것은145개이며 나머지 기록을 필수 선수로 자동 승격하지 않았다. 기준 단위의 기존 전체 관계 검토 상태도 일괄 완료로 바꾸지 않았다. 새 목표별 과제 연결은 각 과제에 한정한 부분 수행의 자체 판정이다.

원문 문장·해설의 텍스트 대조와 원문 이미지 대조도 구별한다. 이미지 미대조 상태를 텍스트 점검으로 덮어쓰지 않는다. 독립 검토와 학생 반응 검증은 각각0건이다. 다음 단계의 실제 대상과 기록 방법은 [독립 검토와학생 검증 목록](독립검토와학생검증목록.md)에 정리했다.
