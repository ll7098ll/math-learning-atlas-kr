## 공개 파일과 로컬 파일

Git은 기존 원장의 SHA256을 유지하도록 자동 줄바꿈 변환을 끈다. 임시 작업본, 중첩 `.git`, 원문 PDF, 원문 페이지 이미지와 인증 파일은 기본 제외한다. 제외된 파일에 연결했던 문서 링크 14개는 로컬 보존 경로로 표시하여 GitHub에서 깨진 링크가 되지 않게 했다.
