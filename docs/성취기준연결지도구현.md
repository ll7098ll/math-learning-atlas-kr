# 성취기준 연결 지도

2026년 10월 29일

전체 조망의 46개 개념에서 ‘성취기준 연결’을 열면 해당 기준 전체를 초·중·고 세 열의 노드로 표시한다. 기준 사이의 실제 관계 기록만 SVG 연결선으로 표시하고, 같은 두 기준의 여러 기록은 한 선으로 묶는다. 근거 본문에서는 여러 설명을 보존한다.

기준을 선택하면 직접 연결된 기준과 선을 청록색으로 강조하고 나머지 기준은 흐리게 표시한다. 다른 개념에 속한 직접 연결 기준도 점선 테두리로 추가하며 연결된 기준은 각 학교급의 위쪽에 모은다. ‘개념 안에서 연결 따라가기’는 같은 개념의 기록을 방향과 무관하게 탐색하고, 여러 관계를 거쳐 이어지는 기준을 금색 점선으로 구별한다. 필수 선수 순서나 검증된 학생 발달 단계로 해석하지 않는다.

학교급을 건너뛰는 연결은 중간 학교급 카드의 바깥 여백을 지나도록 배치했다. 특정 학교급에 실제 관계가 없으면 빈 상태를 표시한다. 행렬처럼 고교에 직접 분류된 기준만 있는 개념에서도 해당 고교 기준을 선택하면 실제 기록이 있는 초등 기준을 함께 확인할 수 있다.

선택 기준과 연결 탐색 방식은 `flowNode`, `flowReach`에 보존한다. 상세 화면 왕복에서는 선택, 지도 내부 스크롤, 초점을 복원한다. 모바일에서는 지도 영역 안에서 가로·세로로 이동하며 페이지 자체는 가로로 넘치지 않는다.
