# 초중고 수학 사고 분석과 연결 연구 계획

연구 목표는 초중고 수학의 모든 성취기준에서 학생이 구성해야 하는 의미와 사고를 밝히고, 그 이해가 다른 영역과 이후 수학에서 어떻게 쓰이고 달라지는지 설명하는 것이다. 교사는 이를 통해 필요한 학습 경험을 설계하고 학생의 어려움을 구체적으로 진단할 수 있어야 한다.

## 분석 범위

| 구분 | 범위 | 분석의 깊이 |
|---|---|---|
| 초등학교 | 네 영역의 성취기준 121개 전체 | 목표의 하위요소, 수행 과정, 선수 조건, 표상, 오류, 진단, 학습 활동을 상세 분석 |
| 중학교 | 성취기준 60개 전체 상세 분석 | 목표 하위요소, 대표 과제, 선수 조건, 표상, 진단, 학습 경로와 연결을 분석 |
| 고등학교 | 공통과 선택 15개 과목 성취기준 254개 전체 상세 분석 | 목표별 사고를 분해하고 초등의 출발 의미와 중간 개념, 과목 분기 및 후속 학습을 분석 |
| 교육과정 밖의 기초 | 세기, 단위화, 보존, 분해와 합성, 공간적 조작 등 | 특정 학년의 성취기준에 적히지 않아도 학습에 필요한 요소로 기록 |

고등학교의 기본수학, 공통수학, 선택 과목은 교육과정상 분기와 대체 관계를 갖는다. 모든 과목을 학생이 순서대로 이수하는 하나의 사슬로 표현하지 않는다. 한 초등 성취기준이 모든 고등 과목으로 직접 이어져야 한다고 가정하지 않는다.

기준 문서는 제공된 2022년 고시 원문이다. 개정 문서를 추가하면 적용 버전과 변경 이력을 분리하고 코드가 같아도 문장이 같은지 확인한다.

## 핵심 연구 질문

1. 성취기준의 개념과 수행을 어떤 세부 판단과 사고로 나눌 수 있는가?
2. 각 요소는 어떤 상황에서 필요하며 다른 접근 경로는 무엇인가?
3. 학생의 설명과 표상에서 그 이해를 어떻게 식별할 수 있는가?
4. 정답은 같아도 의미가 다른 반응을 어떤 대조 과제로 구별할 수 있는가?
5. 여러 영역에서 반복되는 공통 사고는 무엇인가?
6. 이후 개념을 배우면서 기존 이해를 어떻게 확장하거나 수정해야 하는가?
7. 수학적 연결, 학습의 선수 조건, 가르치는 순서를 각각 어떤 근거로 주장할 수 있는가?

## 작업 단계와 산출물

| 단계 | 주요 작업 | 산출물 | 다음 단계로 넘어가는 조건 |
|---|---|---|---|
| 전체 목록 | 성취기준 코드, 문장, 학교급, 과목, 영역, 원문 위치 정리 | 전체 색인과 원문 추출 품질 기록 | 코드 중복과 번호 누락을 점검하고 수식 오류를 식별 |
| 분석 규칙 | 분석 단위, 관계 유형, 근거 표시, 상태 정의 | 분석 규칙과 작성 양식 | 서로 다른 작성자가 같은 구분으로 읽을 수 있음 |
| 시범 분석 | 몫과 분수, 비율, 평면도형 넓이 분석 | 세 가지 상세 분석과 연결 사례 | 산술과 기하에서 양식의 유효성을 검토 |
| 초등 전체 분석 | 영역을 순환하며 성취기준별 분석, 공통 요소 통합 | 121개 상세 분석 기록 | 모든 항목에 목표, 하위요소, 진단, 연결 검토가 존재 |
| 중고등 연계 | 초등에서 정방향 추적하고 중고등에서 역방향 검토 | 전환 지점과 중간 개념이 있는 연결 기록 | 직접 연결과 간접 연결, 추가 조건을 구분 |
| 연구와 수업 검토 | 원문 논문 검토, 수학적 타당성 검토, 교사 검토 | 근거가 보강된 분석과 수정 이력 | 다른 풀이와 반례를 견디며 주장의 범위가 분명함 |
| 학생 반응 검증 | 가능한 경우 설명, 그림, 조작, 전이 과제의 반응 분석 | 진단과 학습 경로의 수정 근거 | 실제 반응 자료가 연결 주장과 어떻게 대응하는지 기록 |
| 탐색 체계 | 학년군, 영역, 사고, 어려움, 후속 개념별 탐색 | 통합 지도와 활용 안내 | 특정 성취기준에서 기초와 후속 학습을 근거와 함께 조회 |

학생 반응 검증 전에도 수학적 설명과 수업 설계 초안은 작성할 수 있다. 이때 진단의 정확도나 교수 효과가 검증됐다고 표시하지 않는다.

## 초등 전체 분석 순서

첫 묶음은 나눗셈의 의미, 분수의 구성, 몫의 분수 표현, 분수 연산, 비와 비율이다. 이어 넓이와 도형의 분해 및 합성, 자료의 분류와 표현을 분석해 수 영역에 편중되지 않도록 한다.

이후에는 네 영역을 순환한다. 각 묶음의 크기는 성취기준의 개수보다 개념의 밀도로 정한다. 예를 들어 평행사변형, 삼각형, 사다리꼴, 마름모를 포함하는 한 성취기준은 도형별 경로를 모두 다뤄야 한다. 공통 요소를 재사용하더라도 각 목표의 고유한 조건과 진단 질문을 생략하지 않는다.

| 연구 묶음 | 조사할 공통 사고 | 중고등 연결의 검토 방향 |
|---|---|---|
| 세기와 자릿값 | 일대일 대응, 묶음을 하나로 보기, 단위 교환 | 수 체계, 문자식의 동류항, 지수 표현 |
| 덧셈과 뺄셈 | 변화, 합병, 비교, 역관계, 보상 | 등식과 방정식, 부호가 있는 수 |
| 곱셈과 나눗셈 | 같은 크기 묶음, 배, 등분제와 포함제, 양의 종류 | 비례, 유리수 연산, 함수 |
| 분수와 소수 | 등분할, 반복, 기준 단위, 동치, 크기 | 유리수, 유리식, 비율, 확률 |
| 규칙과 관계 | 대응, 공변, 불변량, 일반화, 등호 | 문자식, 함수, 수열, 변화율 |
| 도형과 공간 | 분류, 포함 관계, 이동, 구성, 시각화 | 합동, 닮음, 증명, 좌표, 벡터 |
| 측정 | 속성 구별, 단위 반복, 가법성, 차원 | 삼각비, 좌표 기하, 넓이와 적분 |
| 자료와 가능성 | 분류 기준, 자료 수집, 대표성, 변이, 비율 | 통계적 탐구, 확률, 추정 |

이 표는 조사 방향이다. 예를 들어 자릿값과 동류항의 공통성이 발견되더라도 직접적인 선수 관계라는 결론은 별도로 검토한다.

## 문헌 조사 방식

성취기준마다 먼저 설명이 필요한 질문을 만든다. 해당 개념의 수학적 분석, 학생의 사고를 조사한 연구, 표현과 과제를 다룬 연구, 교수 효과 연구를 구분하여 찾는다. 이론 이름이나 논문 수를 늘리는 것보다 분석의 빈 부분을 채우는 근거를 우선한다.

국내 연구와 해외 연구를 함께 검토하고, 연구 대상의 학년, 표본, 과제, 교육과정, 방법을 확인한다. 초록만 확인한 논문은 내용 전체를 검토한 자료와 구분한다. 연구의 참고문헌과 후속 연구를 추적하되 수학적 타당성과 학습 효과의 근거를 혼합하지 않는다.

## 완료 기준

- 초등 121개 모두에 상세 분석과 중고등 연결 검토 기록이 있다.
- 중학교 60개와 고등학교 254개 모두에 같은 분석 항목이 있고 과목별 범위를 구별한다.
- 각각의 하위요소에 구체적인 수행이나 진단 질문이 연결된다.
- 연결마다 왜 이어지는지, 어떤 조건에서 성립하는지, 무엇을 더 배워야 하는지가 적혀 있다.
- 성취기준의 명칭만 나열한 중고등 연결은 완료로 세지 않는다.
- 직접 연결이 적절하지 않은 경우 그 검토 결과를 남긴다.
- 문헌의 근거와 연구자의 분석, 수업 설계안의 상태가 구별된다.
- 학생 반응 검증을 수행했다면 대상, 과제, 관찰, 해석의 범위를 기록한다.

## 현재 우선 작업

초등 121개와 중고등 314개 전체에 상세 초안이 작성되었다. 다음 단계에서는 영역별로 수학적 논증과 원문 범위, 연결의 추가 개념을 검토한다. 한 목표 안의 여러 내용이 모두 충분히 분해됐는지도 계속 확인한다. 연구를 통해 관찰된 학습 경로와 자체 설계한 경로를 대조하고 진단의 구별력을 보완한다. 원연구 검토와 학생 반응 검증이 끝나기 전에는 해당 단계의 완료로 표시하지 않는다. 포털 제작은 전체 분석 자료를 바탕으로 재개한다.
