# 수학의 연결 지도 개편안 | 처음 찾는 기준에서 수업 질문까지

2026년 11월 26일 · 사용자 여정 검토와 설계 제안

같은 날 실제 포털의 학교급별 탐색, 전체 성취기준 상세·비교, 개념·과제·자료 화면에 적용했다. 아래 사용성 시험의 인원과 시간은 후속 참여자 시험의 목표다. [구현 및 로컬 검증 결과](VERIFICATION.md#2026년-11월-26일-포털-전체-화면-개편)

개편 뒤에는 분석 원고 435건과 대표 화면을 다시 읽고, 교사가 수업에 가져갈 질문과 학생 답에서 살펴볼 점을 중심으로 다음 편집 계획을 세웠다. [분석 문장과 읽기 화면 개선 계획](#분석-문장과-읽기-화면-개선-계획)

**첫 방문자는 자기 학년이나 익숙한 개념에서 시작하고, 기준 하나를 읽으면 수업에서 던질 질문 하나를 가져갈 수 있게 한다.** 이미 코드를 아는 방문자는 첫 검색창이나 공유 주소로 곧장 들어간다. 개편의 첫 단위는 홈 한 장이 아니라 **찾기 → 읽기 → 과제 사용 → 읽던 자리로 복귀**하는 하나의 수업 준비 과정이다.

## 현행 포털에서 어디가 막히는가

로컬 포털을 데스크톱 1440×900과 모바일 크기 390×844의 Chromium에서 열었다. 검색 예시 ‘분수’를 누르고 초등학교와 3~4학년군을 선택한 뒤 5개 결과 중 `4수01-09`를 읽었다. 아래 수치는 이 기준과 두 뷰포트에서 관찰한 값이다. 실제 교사가 겪는 어려움의 빈도와 소요 시간은 후속 시험에서 측정한다.

| 지점 | 관찰한 동작 | 설계 판단 |
| --- | --- | --- |
| 첫 방문 | 검색 예시와 분수·소수 그림, 학교급 선택 아래에 전체 435개 기준 중 첫 24개가 나온다. 휴대폰 크기에서 첫 기준은 문서 상단으로부터 약 725px에 시작했다. | 처음 보는 사람은 무엇을 고르면 자기 수업 범위가 되는지 먼저 알아야 한다. 학교급 선택을 첫 행동으로 올리고 전체 목록은 이름이 보이는 링크로 둔다. |
| 기준에서 수업으로 | `4수01-09`의 해설과 공식 원문 아래에 연결 기준 7개 중 2개의 설명이 먼저 나온다. ‘수업 과제와 상세 해설’은 PC 약 990px, 모바일 약 1,346px에서 시작하고, 진단 질문을 읽으려면 한 번 더 펼친다. | 원문 바로 아래에 대표 과제의 질문과 관찰점을 보여준다. 연결을 보러 온 사람도 같은 자리에서 ‘이 기준의 연결’로 건너갈 수 있게 한다. |
| 지도의 목적지 | PC에서 상단 ‘연결 지도’는 46개 개념군 탐색을 연다. 상세의 같은 이름은 선택 기준을 포함한 전체 그래프를 연다. | 첫 링크는 ‘개념으로 둘러보기’, 둘째는 ‘이 기준의 연결 보기’로 이름을 붙인다. 상세에서는 관계 설명을 먼저 읽고 필요할 때 전체 지도를 연다. |
| 돌아오기 | 연결된 기준을 읽고 ‘찾아보던 목록으로’를 누르면 분수 검색과 선택 행의 초점이 복원됐다. 반면 ‘과제별 경로와 전체 조건’에서 ‘성취기준 상세로’를 누르면 같은 기준에 복귀해도 다음 링크가 ‘영역 목록으로’로 바뀌었다. | 상세·과제·연결 근거 사이를 이동할 때도 원래 검색어, 범위, 행, 스크롤을 이어준다. 화면에 보이는 복귀 링크와 브라우저 뒤로가기를 각각 검사한다. |

현재 홈은 교육과정 탐색기다. 검색 예시, 코드 검색, 목록에서 바로 읽는 공식 문장, 기준별 출처와 PDF 쪽수, 검색 결과로의 초점 복원은 다음 설계의 출발점이다. 11월 19일 계획에 기록된 첫 화면은 당시의 전체 연결망이었다. [기존 계획](CURRICULUM_UX_PLAN.md) · [현행 탐색 화면](../site/frontend/src/browse.jsx) · [현행 기준 상세](../site/frontend/src/reading.jsx)

## 누가 어디서 시작해서 무엇을 얻는가

수업을 준비하는 교사를 1차 사용자로 가정한다. 첫 방문자의 ‘교육과정 코드 모름’과 재방문자의 ‘코드를 정확히 앎’을 서로 다른 출발점으로 설계한다.

| 방문자의 질문 | 제안하는 경로 | 끝났다고 판단할 수 있는 일 |
| --- | --- | --- |
| “다음 학기에 처음 맡을 초등 5~6학년 수학에서 무엇을 다루지?” | 홈의 ‘초등학교’ → ‘5~6학년군’ → ‘이 학년군 한눈에’ → ‘수와 연산’ → 기준 선택 | 공식 핵심 아이디어의 적용 범위를 말하고 선택한 기준의 공식 원문과 쪽수를 찾는다. 고교에서는 학교급 다음에 과목을 고른다. |
| “자연수끼리 나눈 몫이 왜 분수가 되는지 어떻게 설명하게 할까?” | ‘분수’ 검색 → 초등 5~6학년군으로 좁히기 → `6수01-10` → 대표 수업 질문 → 필요하면 과제 해설 | 질문 한 개와 답에서 관찰할 점 한 개를 가져가고, 처음 읽던 검색 결과로 돌아온다. |
| “초등에서 배운 분수는 중학교에서 어떻게 달라지지?” | ‘개념으로 둘러보기’ → ‘분수·소수·유리수’ → 학년군별 기준 → `6수01-10`과 `9수01-03`의 연결 이유 | 자연수의 몫에서 정수의 비와 부호로 확장되는 점을 읽는다. 두 범위의 공식 문장을 나란히 보려면 ‘이 두 범위 비교’를 연다. [개념군 색인](../site/dist/content/concept-pathways-index.json) · [관계 원장](../data/revised_relations.json) |
| “동료가 보낸 기준이나 과제의 근거를 확인하고 싶다.” | 코드 검색 또는 기존 공유 주소 → 해당 기준·과제 → ‘적용 조건과 근거’ → 해당 문헌의 지원 범위 | 특정 목표에 필요한 조건과 대안 경로를 구분하고, 읽던 위치를 공유하거나 같은 기준으로 복귀한다. |

## 화면을 어떻게 바꿀 것인가

| 화면 | 처음 보이는 내용과 주 행동 | 한 단계 더 들어가면 |
| --- | --- | --- |
| 홈 | ‘어느 학교급의 수학을 보시나요?’ 아래 초등학교·중학교·고등학교. 바로 곁에 ‘개념 또는 성취기준 코드 검색’. 단어가 떠오르지 않으면 기존 분수 그림에서 ‘분수는 중학교에서 어떻게 이어질까?’ 예시로 들어간다. | ‘개념으로 둘러보기’와 ‘전체 성취기준 435개 보기’를 제공한다. 전체 목록은 한 번에 접근 가능하고 선정 예시는 명시한다. |
| 학년군·과목 한눈에 | 선택 범위, 공식 영역, 해당 범위에 적용되는 핵심 아이디어와 기준 수. 영역 이름을 누르면 해당 기준의 제목과 공식 문장 목록을 연다. | 공식 내용 체계의 네 범주, PDF 원문과 두 범위 비교를 연다. 중학교의 공식 단위는 1~3학년군으로 표시한다. 고교는 15과목의 과목 유형과 기본수학의 대체 이수 안내를 살린다. |
| 검색 결과 | 입력한 개념이나 코드, 적용된 범위, 결과 수가 한 줄의 맥락이 된다. 코드 일치는 첫 행에, 일반 검색은 학교급·학년군과 원문을 함께 표시한다. | 한 검색어에 연구용 개념군이 대응하면 해당 개념군으로 가는 링크를 준다. 결과가 없으면 검색어를 유지한 채 범위를 넓힌다. |
| 성취기준 상세 | 위치와 코드 → 공식 원문·쪽수 → 짧은 자체 해설 → 대표 질문과 관찰점. 원문 아래에서 ‘수업 질문’과 ‘이 기준의 연결’로 바로 이동할 수 있다. | 상세 과제, 관련 기준, 근거와 검토 이력, 기존 전체 분석 목차와 인쇄를 연다. 대표 과제가 없는 항목은 실제로 있는 목표·자료로 안내한다. |
| 개념·비교·심화 | 개념 화면은 해당 학년군의 기준과 무엇이 달라지는지 보여준다. 비교 화면은 출발한 범위를 미리 채운다. 과제 화면은 사용자가 선택한 목표와 질문으로 열린다. | 기존 전체 그래프와 자료 안내, 문헌·통계 실험실·탐구 기록지는 직접 주소와 메뉴를 유지한다. 비교 행은 주제별 대조로 읽고, 연구 연결은 관계 유형과 이유로 읽는다. |

휴대폰에서는 학교급 → 학년군 또는 과목 → 영역을 한 열로 고른다. 선택한 범위는 접힌 뒤에도 한 줄로 보인다. 상세 본문은 원문·질문·관찰점 순서로 읽고 두 범위 비교는 항목마다 두 원문을 세로로 짝짓는다. 데스크톱은 선택 범위와 본문, 비교할 두 문장에만 가로 공간을 쓴다. 두 환경 모두 키보드로 열고 닫으면 선택했던 항목으로 초점이 돌아간다.

| 고교 `12확통02-02` · “교집합이 두 번 포함되는 것을 한 번 제거한다.” | “공정한 주사위에서 짝수가 나올 확률과 3의 배수가 나올 확률을 더하면, 6이 나오는 경우를 두 번 센다. 둘 중 적어도 하나에 해당할 확률을 구하려면 6이 나올 확률인 1/6을 한 번 뺀다.” 바로 아래에 일반식과 배반일 때의 조건을 둔다. |

같은 확률 기준에서 기대 답 “다른 관계”도 구체화한다. “배반인 두 사건은 함께 일어날 수 없다. 독립인 두 사건이 함께 일어날 확률은 두 사건의 확률을 곱한 값이다.” 그러면 교사는 두 사건의 확률이 모두 양수일 때 배반인 두 사건이 왜 독립일 수 없는지 이어 물을 수 있다. [구슬 세기 원고](../analyses/2수01-01.md) · [소인수분해 원고](../analyses/9수01-01.md) · [확률의 덧셈정리 원고](../analyses/12확통02-02.md)

세부 사고는 관찰할 수 있는 수행과 짝짓는다. 예컨대 구슬을 넓게 펴자 수가 늘었다고 답하면, 다음에는 구슬을 하나씩 대응시켜 보게 한다. 예상 답과 가능한 해석은 문구로 구별하고, 실제로 관찰한 학생 발언은 별도 기록을 갖춘 경우에 인용한다. 식·부호·단위는 풀이 단계와 함께 읽고, 통계 과제는 가상 자료·모형 계산·공개 관측 자료 중 어느 것인지 수치 옆에 밝힌다.

### 화면에서 어떤 순서로 읽을까

1. **찾기와 비교** — 학교급·학년군과 코드 검색을 그대로 입구로 쓴다. ‘분수’ 검색에서는 같은 결과 제목이 두 번 나온다. 제목은 한 번 두고 그 아래 결과 수와 기준 목록을 둔다. 좁은 화면에서 두 기준을 비교할 때는 각 원문 위에 학교급·과목과 코드를 붙여 ‘왼쪽·오른쪽’ 없이도 대상을 알 수 있게 한다.
2. **기본 상세** — 공식 성취기준과 PDF 쪽수 다음에 ‘핵심 의미 → 학생에게 물어볼 질문 → 답에서 살펴볼 점’을 둔다. 지금은 ‘쉽게 읽기’를 누르면 ‘무엇을 배우나요?’로 이동한다. 목차와 도착한 절 제목을 ‘핵심 의미’로 맞춘다. 문제를 풀 때 알아야 할 조건은 질문 곁에 두고, 풀이를 펼치면 그 조건을 어디에 쓰는지 읽게 한다.
3. **과제와 연결 지도** — 과제 제목에 나온 수와 본문의 수부터 맞춘다. 예를 들어 `6수01-10`의 빵 과제 제목은 ‘3개와 5개’이고 문제에는 4개도 있다. 목표 하나에 풀이가 여럿이면 방법마다 함께 필요한 조건을 모두 보인다. 지도에서 연 연결의 이름·이유·적용 목표를 같은 순서로 읽고, 돌아가면 고른 기준과 위치를 복원한다.
4. **전체 원고와 근거** — 기존 12절의 주소를 유지하며 목차를 ‘기준의 뜻’, ‘풀이와 수업’, ‘다른 기준과의 연결’, ‘근거와 검토’로 묶는다. 제목과 하위 제목의 깊이를 화면과 읽기 도구에 전달한다. 긴 진단은 질문별로, 문헌은 주장별로 펼쳐 출처·지원 범위·한계를 함께 읽는다. 실제 수치 비교에는 표를 유지하고, 인쇄할 때는 펼친 상태에 관계없이 전문을 읽을 수 있게 한다.

데스크톱 시안에서는 긴 해설의 줄 길이를 줄이고, 여백으로 질문과 답 한 쌍의 경계를 보인다. 휴대폰에서는 같은 쌍을 한 열에 놓고 긴 계산식은 등호를 기준으로 줄을 나눈다. ‘공식 원문’, ‘예상 답’, ‘공개 관측 자료’ 같은 구분은 색과 함께 글자로도 표시해 흑백 인쇄에서도 읽을 수 있게 한다.

### 적용 순서와 통과 기준

| 순서 | 작업 | 다음 단계로 넘어가는 기준 |
|---|---|---|
| 1. 대표 원고 네 편 | 구슬 세기, 소인수분해, 확률의 덧셈정리, 두 방식으로 3m의 끈을 나누는 초기 분수 사례에 편집 전후 원고와 모바일·PC 시안을 만든다. | 각 사례에서 공식 문구·수치·단위·적용 목표·풀이 조건·근거를 대조한다. 분수 사례는 두 풀이가 각각 어떤 양을 등분하는지 설명할 수 있어야 한다. |
