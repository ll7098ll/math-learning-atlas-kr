# 학교급별 탐색과 성취기준 상세 분석 전면 정비 계획

작성일: 2026년 10월 29일

초등 121개, 중학교 60개, 고등학교 254개 전체를 처음 작성한 초등 상세 분석의 깊이로 정비한다. 각 성취기준에서 무엇을 이해해야 하는지, 어떤 사고가 필요한지, 어떻게 설명하고 진단하는지, 같은 학교급 안에서 무엇과 어떤 관계를 갖는지까지 개별적으로 작성한다. 학교급을 선택하면 그 학교급의 자료와 내부 관계를 집중해서 볼 수 있게 한다.

기준 사례는 [나눗셈의 몫을 분수로 나타내기](../analyses/6수01-10.md), [비율의 분수 소수 백분율 표현](../analyses/6수02-03.md), [여러 평면도형의 넓이 추론](../analyses/6수03-14.md)이다. 세 사례의 구체적인 과제, 의미 분해, 경로 비교, 반례, 진단과 피드백을 전체 분석의 품질 기준으로 삼는다. 문서 길이와 사고 요소 수를 똑같이 맞추지 않고, 각 목표를 빠짐없이 설명하는 깊이를 맞춘다.

이번 산출물은 점검에 근거한 수정 계획이다. 실제 자료의 재작성과 화면 변경은 아래 실행 단계에서 수행한다.

## 확인한 현재 상태

435개 문서의 절 구조와 관계 데이터는 전수 집계했고, 수학적 내용은 초기 초등 세 사례와 학교급별 대표 문서를 읽어 점검했다. 435개 전체의 내용 검토 완료를 뜻하지 않는다. 점검 기준 소스는 기존 배포 기록과 일치하는 `tmp/pathways-release`의 커밋 `24e4934189400aac2f16d67cfb9292352ecd2461`이다. Sites 조회에서 현재 사이트는 활성 상태이며 최신 버전 번호는 9였다.

| 점검 항목 | 확인한 상태 | 수정의 핵심 |
|---|---|---|
| 학교급 선택 | 검색에서는 제외, 위계에서는 강조, 전체 연결망에는 학교급 선택 없음 | 모든 화면에 같은 범위 선택 규칙 적용 |
| 문서 구조 | 초등 일반형 118개, 초기 초등 세 사례 각각, 중고등 공통형 314개로 절 구조 5종 | 공통 문서 체계와 학교급별 개별 내용 정비 |
| 사고 분석 | 중고등의 사고 표는 의미와 관찰 수행을 별도 필드로 구분하지 않음 | 사고의 의미와 확인할 수행을 각각 작성 |
| 과제별 조건 | 소인수분해 문서에 분모와 제곱근의 조건이 삽입됨 | 공통 설명의 목표 적합성을 전수 확인 |
| 함께 필요한 조건 | 생성기가 432개 문서의 첫 두 사고 요소를 자동으로 AND 조건으로 서술 | 실제 과제와 경로에서 확인한 조건만 명시 |
| 데이터 선택 | 중등 측정 2개 기준에 초등 측정 프로필이 선택됨 | 학교급별 자료 식별과 생성 규칙 수정 |
| 상세 표시 | 절 제목 판별 방식 때문에 432개 문서의 일부 주요 내용이 추가 해설로 다시 들어감 | 안정적인 절 식별자로 중복 표시 제거 |

성취기준 사이의 관계 기록은 1,518건이며, 그중 학교급 내부는 352건, 학교급 사이는 1,166건이다. 아래 수치는 하위 사고 관계를 제외한 **성취기준 간 기록 수**다. 같은 두 기준에 서로 다른 설명이 붙을 수 있으므로 단순한 두 기준의 쌍 수와 구별한다.

| 학교급 | 성취기준 | 내부 관계 기록 | 내부 관계에 닿는 기준 | 내부 연결 미기록 기준 | 내부 의미 확장 방향 기록 |
|---|---:|---:|---:|---:|---:|
| 초등학교 | 121 | 1 | 2 | 119 | 0 |
| 중학교 | 60 | 33 | 36 | 24 | 0 |
| 고등학교 | 254 | 318 | 246 | 8 | 0 |

초등 내부 1건은 의미 연결, 중학교는 의미 연결 32건과 대조 1건, 고등학교는 모두 의미 연결이다. 고등 내부 기록은 같은 과목 안 141건과 다른 과목 사이 177건으로 나뉜다. 기존 의미 확장 135건은 모두 학교급 사이에 있다. 내부 연결 미기록은 교육적으로 관계가 없다는 판정이 아니다.

초등 118개 분석의 원고 데이터에는 내부 선수 후보 175쌍이 이미 있다. 이 후보는 문서에만 표시되고 관계 데이터에는 출력되지 않는다. 이를 재검토의 출발 자료로 사용하되, 후보라는 이유만으로 필수 선수 관계로 확정하지 않는다. 초기 초등 세 사례의 상세 연결 표도 함께 수집한다.

## 처음 만든 초등 분석을 전체 품질 기준으로 삼기

초기 사례에서 유지해야 할 수준은 다음과 같다. 같은 질문에 모든 학교급의 문서가 답할 수 있어야 한다.

| 품질 기준 | 초기 사례에서 확인할 수 있는 수준 | 전체 문서의 완료 조건 |
|---|---|---|
| 목표 전체의 분석 | 넓이 기준에서 평행사변형·삼각형·사다리꼴·마름모를 각각 설명 | 한 기준 안의 복수 대상과 수행을 모두 분석하고 빠진 부분이 없음 |
| 구체적인 대표 과제 | 3m 끈을 네 사람에게 나누고 한 몫을 다시 합쳐 검산 | 수치·상황·질문·기대 설명이 실제로 주어지고 풀이를 따라갈 수 있음 |
| 개념의 의미와 조건 | 전체 3m의 1/4과 기준 단위 1m의 3/4를 구별 | 기호·대상·단위·정의·성립 조건을 해당 목표에 맞게 설명 |
| 세부 사고의 분석 | 등분·단위 조정·반복·역관계 등을 수행과 연결 | 각 사고의 역할, 필요한 이유, 관찰 가능한 설명이나 행동이 있음 |
| 대안 경로 | 전체를 바로 나누는 방법과 각 1m를 나누는 방법 비교 | 실제로 성립하는 경로별 단계·조건·공통점·차이를 설명 |
| 적용 한계와 반례 | 대각선 곱의 절반을 임의의 사각형에 적용하면 안 되는 이유 | 적용 범위를 확인할 경계 사례나 반례를 목표에 맞게 제시 |
| 진단과 후속 확인 | 답을 맞혀도 기준량을 혼동하는지 추가 질문 | 질문·기대 설명·가능한 해석·구별할 후속 질문이 연결됨 |
| 활동과 피드백 | 조각 수만 세는 반응에 조각의 길이가 같은지 되묻기 | 학생의 구체적 반응에 따라 다음 활동과 발문이 달라짐 |
| 관계의 설명 | 넓이에서 단위넓이·직사각형 배열·분해와 합성의 역할 설명 | 연결 대상뿐 아니라 사용되는 사고·추가 학습·조건을 설명 |

하나의 기준을 4개 사고와 2개 진단으로 고정하지 않는다. 복합 기준에는 하위 목표별 과제와 진단이 필요하며, 대안 풀이가 성립하지 않는 경우에는 억지로 경로를 추가하지 않고 그 이유를 기록한다. 초등의 구체물 설명을 중고등에 반복하기보다 해당 목표에 맞는 식, 그래프, 도형, 증명, 자료와 모델을 사용한다.

각 기준은 원고를 읽고 대표 과제를 재현할 수 있는 수준까지 작성한다. 공통 프로필의 설명만 있고 해당 목표의 조건·풀이·진단이 없는 문서는 완료로 처리하지 않는다. 초기 세 사례도 새로운 공통 체계로 옮길 때 내용을 축약하지 않으며, 부족한 내부 관계와 근거는 같은 기준으로 보완한다.

## 모든 학교급에 적용할 문서 체계

다음 순서와 항목을 분석 원고와 포털 상세에 공통으로 적용한다. 복합 목표는 관련 절 안에서 하위 목표별로 펼친다.

| 순서 | 공통 절 | 반드시 담을 내용 |
|---:|---|---|
| 1 | 공식 성취기준과 범위 | 코드·원문·학교급·학년군·과목·출처 위치·해설·적용 범위 |
| 2 | 핵심 의미와 목표 수행 | 무엇을 이해하고 할 수 있어야 하는지, 하위 목표, 포함하지 않는 범위 |
| 3 | 대표 과제와 성공한 수행 | 구체적 문제·상황·자료, 기대 답과 설명, 성공 판단의 근거 |
| 4 | 수학적 의미와 성립 조건 | 정의·성질·단위·관계식·정당화·적용 조건·경계 사례 |
| 5 | 세부 사고와 관찰할 수행 | 사고 요소·구성할 의미·필요한 이유·관찰할 수행·경로별 조건 |
| 6 | 수행 과정과 대안 경로 | 단계별 풀이와 이유, 함께 필요한 조건, 대안의 차이와 한계 |
| 7 | 표현 사이의 대응 | 상황·그림·표·그래프·식·말 사이에서 보존되는 의미와 추가 해석 |
| 8 | 오류와 진단 및 후속 질문 | 목표별 질문·기대 설명·가능한 해석·구별할 후속 질문 |
| 9 | 학습 활동과 피드백 | 각 활동이 돕는 사고, 교사 발문, 반응에 따른 피드백 |
| 10 | 같은 학교급 안의 관계와 위계 | 앞선 기초·이후 확장·함께 비교할 관계, 적용 조건과 판단 근거 |
| 11 | 다른 학교급으로 이어지는 관계 | 유지되는 의미·중간 개념·추가 사고·직접 또는 간접 연결 |
| 12 | 근거와 검토 상태 | 원문 대조·수학적 검토·관계 검토·문헌 확인·학생 반응·미해결 질문 |

설명은 ‘무엇을 뜻한다 → 왜 그런가 → 어떤 조건에서 성립하는가 → 어떻게 확인하는가’의 흐름으로 쓴다. 본문은 설명형 문장으로, 학생 발문은 직접 물을 수 있는 질문으로, 관찰 수행은 행동이 드러나는 동사로 적는다. 원문과 분석자의 설명은 구별하고 원문을 문체 통일 대상으로 바꾸지 않는다.

관계 설명은 ‘출발의 어떤 사고가 도착의 어떤 수행에 쓰이는가 → 도착에서 새로 구성할 의미 → 적용 조건과 다른 경로 → 근거와 상태’로 통일한다. ‘관련이 있다’, ‘확장된다’로 끝나는 문장은 구체적인 관계 설명으로 고친다. 학교급 명칭, 관계 유형, 검토 상태, 수학 기호, 단위, 조사와 띄어쓰기 규칙을 하나의 편집 기준으로 관리한다.

## 학교급 내부 관계와 위계의 전수 검토

435개 각각에 내부 관계 검토 기록을 만든다. 학년군과 과목 사이뿐 아니라 같은 학년군·같은 과목·서로 다른 영역 사이의 관계도 검토한다. 기존 46개 개념군은 탐색 단위로 쓰되, 분류가 다르다는 이유로 필요한 내부 연결을 제외하지 않는다.

| 범위 | 검토 단위 | 집중해서 확인할 관계 |
|---|---|---|
| 초등 121개 | 1~2·3~4·5~6학년군 각각과 학년군 사이 | 수 개념과 연산, 분수와 소수, 규칙과 관계, 도형과 측정, 자료 해석의 세부 사고 연결 |
| 중학교 60개 | 공식 1~3학년군의 모든 기준과 영역 | 같은 영역 안의 의미 변화, 수와 식·함수·기하·확률 및 통계 사이의 연결 |
| 고등학교 254개 | 15개 각 과목 내부와 과목 사이 | 공통·기본의 평행 관계, 선택 과목의 분기, 정의·표현·정당화·모델의 확장 |

교육과정에 없는 중학교 개별 학년과 학기 순서를 추정하지 않는다. 고등학교 과목을 하나의 필수 이수 사슬로 만들지 않는다. 공식 배치와 과제에서의 논리적 의존, 학생의 학습 과정은 구별한다.

각 관계 후보는 다음 순서로 판단한다.

1. 도착 기준의 구체적인 하위 목표와 수행을 정한다.
2. 출발 기준 중 실제로 사용되는 사고를 찾는다. 출발 기준 전체를 필수 선수로 묶지 않는다.
3. 적용 과제·표현·수 범위와 필요한 이유를 적는다.
4. 그 사고 없이 가능한 다른 풀이와 성립하지 않는 사례를 확인한다.
5. 관계 종류와 방향을 판단하고, 함께 필요한 조건과 대안 경로를 기록한다.
6. 관계를 확인할 질문·기대 설명·근거·검토 이력을 남긴다.

| 관계 종류 | 설명할 내용 | 위계에서의 처리 |
|---|---|---|
| 과제별 필요 조건 | 특정 수행과 경로에서 필요한 사고 | 조건을 검토한 범위에서만 선후를 표현 |
| 의미 확장 | 기존 의미를 유지하며 새 대상이나 조건을 추가 | 확장 방향으로 표시하며 필수 숙달 순서와 구별 |
| 의미 연결과 대조 | 함께 해석할 구조와 구별할 차이 | 순서를 강제하지 않음 |
| 학습 지원 | 이해를 돕는 경험과 그 근거 | 필수 선수로 바꾸지 않음 |
| 수업 순서 제안 | 선택한 수업에서의 진행과 이유 | 해당 수업 경로에 한정 |
| 병렬과 대안 | 함께 다루거나 서로 다른 경로로 접근하는 관계 | 병렬 배치와 분기를 허용 |

초등 선수 후보 175쌍, 초기 세 사례의 연결 표, 중고등 이전·후속 목표 기록, 기존 내부 관계 352건을 시작 목록으로 사용한다. 기존 목록 밖의 관계도 목표에서 역으로 검토한다. 모든 기준에 선을 하나 이상 만드는 대신, ‘관계 기록 있음’, ‘검토 후 연결 보류 또는 해당 관계 없음’, ‘미검토’를 구별한다.

같은 관계가 두 문서에서 설명될 때 출발·도착·조건·유형이 서로 맞는지 대조한다. 순서 주장에 순환이 있으면 과제나 경로가 섞였는지 검토하고, 임의로 선을 지워 정렬하지 않는다. 독립 검토와 학생 반응 검증은 실제로 수행한 경우에만 해당 상태로 기록한다.

## 학교급을 선택해서 보는 화면

공통 선택기는 **전체 / 초등 / 중등 / 고등**으로 둔다. ‘초등’을 고르면 기본 화면에는 초등 기준과 초등 기준 사이의 관계만 표시한다. 검색, 전체 연결망, 개념 목록, 연결과 위계, 관련 기준 목록, 건수와 검토 상태에 같은 범위를 적용한다.

| 사용자 동작 | 계획한 동작 |
|---|---|
| 학교급만 선택 | 추가 검색 조건이 없으면 전체 435개, 초등 121개, 중등 60개, 고등 254개를 탐색 가능 |
| 학교급 내부 위계 탐색 | 선택 목표의 기초·목표·확장과 병렬 관계를 표시하고 이유를 바로 확인 |
| 세부 범위 선택 | 초등은 학년군, 중등은 영역·개념, 고등은 과목군·과목으로 좁힘 |
| 다른 학교급 연결 확인 | 기본 해제된 ‘다른 학교급 연결 함께 보기’를 켜서 맥락을 추가 |
| 학교급을 바꿔 목표가 범위 밖이 됨 | 그 범위의 목표 선택을 해제하고 이유와 새 목표 선택을 안내. 범위별 이전 선택은 저장 |
| 다른 학교급 상세의 직접 링크 열기 | 해당 상세는 열고 현재 탐색 범위와 대상 학교급을 표시. 목록으로 돌아가면 기존 범위 복원 |
| 화면 이동·새로고침·뒤로 가기 | 주소와 저장 상태를 통해 학교급, 유효한 세부 조건, 목표와 탐색 위치 유지 |

학교급만 보기에서는 범위 밖 노드와 선을 실제 표시·선택 대상에서 제외한다. 선은 양 끝 기준이 모두 선택 범위 안에 있을 때 표시하며, 숨긴 중간 기준을 건너뛰는 새 화살표를 만들지 않는다. 관계 기록이 없는 기준도 목록에서 빠지지 않는다.

AND 조건 묶음에 다른 학교급의 사고가 있으면 원래 조건 묶음을 보존한다. ‘전체 조건 중 일부가 보기 범위 밖’이라는 안내와 펼쳐 보기를 제공하고, 화면에 남은 조건만으로 충분하다고 표시하지 않는다. 복수 기준에 대응하는 사고 노드는 실제 대응 관계를 확인하여 범위를 정한다.

학교급 내부 보기의 배치는 관계 검토 결과에 맞게 다시 구성한다. 전체 연결망에서 학교급 열만 지워 중학교가 한 열에 몰리는 방식으로 끝내지 않는다. 교육과정 위치와 관계에 따른 위계는 각각 볼 수 있게 하며, 학년군·코드 순서만으로 선수 방향을 만들지 않는다.

빈 상태는 ‘검색 결과 없음’, ‘선택 범위의 소속 기준 없음’, ‘내부 관계 미기록’, ‘방향 위계 미검토’를 구별한다. 현재 전체 범위에서 계산한 ‘의미 확장 초안 33개’ 등의 수치를 학교급 내부 결과로 그대로 표시하지 않는다.

## 생성 원본과 포털을 함께 고치기

내용을 고쳐도 재생성 후 유지되도록 편집 원본, 생성기, 문서, 포털의 연결을 먼저 정리한다.

| 대상 | 계획한 수정 |
|---|---|
| `docs/성취기준분석양식.md`, `docs/분석규칙.md` | 12개 공통 절, 초기 초등 수준의 품질 기준, 내부 관계 판단과 서술 규칙 반영 |
| `data/analysis_details.json`, `data/secondary_analysis_details.json` | 목표별 과제·조건·경로·진단·내부 관계를 명시적으로 기록 |
| 초기 초등 세 원고 | 원본을 보존하고 상세한 내용을 공통 구조에 누락 없이 대응 |
| `scripts/expand_analyses.py`, `scripts/expand_secondary.py` | 첫 두 요소의 AND 자동 서술 제거, 검토한 개별 내용과 관계로 출력 |
| `scripts/build_portal_data.py` | 학교급별 프로필 충돌 해결, 의미와 관찰 수행 분리, 대안 경로와 복합 목표 보존 |
| 관계 데이터와 위계 생성기 | 후보·판정·근거·검토 이력 및 학교급별 내부/외부 집계 추가 |
| 상세 화면 | 제목 문자열 추측을 절 식별자로 교체하고 중복·누락 없이 공통 목차로 출력 |
| 지도·목록·라우터 | 공통 학교급 상태, 범위별 관계와 건수, 내부 위계 배치, 선택 복원 적용 |

공통 프로필은 해당 목표에 맞는 보충 설명으로만 사용한다. 개별 내용이 없으면 미작성 상태를 남겨 작성 대상으로 드러내고, 관련 없는 일반론으로 빈칸을 채우지 않는다. 공식 원문·코드·출처 위치·보정 이력은 분석 서술과 별도로 보존한다.

현재 연구 데이터 생성기는 `portal/math-atlas/dist`에 출력하고 최신 배포 소스는 `tmp/pathways-release`에 있다. 실행 시작 시 배포 저장소와 생성 출력 경로를 일치시켜 최신 연결망 기능을 보존한다. 편집 원본을 확정하고 Markdown과 포털 데이터를 같은 내용에서 출력하며, `--freeze-content`의 역방향 재생성으로 편집 내용이 덮이지 않게 갱신 절차와 검사를 정비한다.

## 실행 순서와 단계별 완료 조건

| 단계 | 작업 | 완료 조건 |
|---:|---|---|
| 1 | 기준 원고와 편집 원본 확정 | 초기 초등 세 문서의 모든 과제·사고·경로·진단을 품질 기준표에 대응. 435개 점검 목록과 현재 데이터 기준선 확보 |
| 2 | 공통 문서 체계와 대표본 작성 | 초등 6개·중등 4개·고등 5개, 총 15개를 새 양식으로 작성. 초기 세 사례를 포함하고 초등 각 학년군·중등 각 영역·고등 과목군을 확인 |
| 3 | 생성·표시 오류 수정과 학교급 선택 구현 | 프로필 충돌, 자동 AND, 중복 절 문제 해결. 네 범위의 화면·주소·건수·목표 처리 일치 |
| 4 | 세 학교급의 전체 원고와 내부 관계 재작성 | 초등 121개·중등 60개·고등 254개 각각을 개별 검토. 복합 목표 누락, 공통 문구 오적용, 내부 관계 미검토를 해소 |
| 5 | 문서 사이 관계 대조와 위계 반영 | 같은 관계의 설명 일치, 조건·대안 보존, 학교급 내부와 학교급 간 연결의 일관성 확인 |
| 6 | 전체 생성과 화면 검증 | 435개 원고·상세·지도·색인의 내용 일치, 재생성 후 보존, 학교급별 탐색과 접근성 확인 |

2단계의 15개는 양식과 품질을 검증할 표본이며 전체 정비의 대체 산출물이 아니다. 공통 기준 확정 후 초등·중등·고등의 원고 작성은 병행하고, 최종 편집 기준과 관계 판정은 함께 대조한다. 4단계 진행 중 발견한 문제는 생성 규칙과 앞서 작성한 문서에도 반영한다.

처음부터 전체 자료를 기계적으로 새 양식에 옮겨 완료 표시하지 않는다. 진행 현황은 학교급별 ‘구조 변환’, ‘개별 내용 점검’, ‘내부 관계 점검’, ‘교차 대조’의 완료 수를 따로 집계한다. 상세 일정은 15개 대표본의 실제 검토량을 확인한 뒤 산정한다.

## 최종 검증과 완료 판단

자동 검사는 435개 코드와 원문 보존, 필수 항목, 하위 목표 참조, 관계 ID와 조건 묶음, 학교급별 필터 결과, 건수 일치, 중복 표시, 재생성 후 차이를 확인한다. 기존 검사가 전제한 ‘범위 밖 목표와 노드를 항상 남김’은 새 학교급만 보기의 규칙에 맞게 바꾸고, 전체 맥락 보기의 조건 보존 검사는 별도로 유지한다.

내용 검토는 각 기준의 과제를 실제로 풀고 의미·조건·단계·대안·진단의 적합성을 확인한다. 특히 소인수분해의 잘못 삽입된 조건, 중학교 부채꼴과 입체 측정의 프로필 충돌, 초기 넓이 기준의 네 하위 목표, 초기 분수 기준의 두 경로를 회귀 점검 사례로 삼는다. 처음 초등 세 사례와 새 원고를 나란히 읽어 설명의 깊이가 유지되는지도 확인한다.

최종 완료 조건은 다음과 같다.

- 435개 모두 공통 문서 체계와 개별 내용 점검 기록을 갖춘다.
- 모든 복합 성취기준의 하위 목표에 설명·과제·진단이 대응한다.
- 모든 기준의 내부 관계 검토 결론과 근거를 남기며, 미검토를 완료로 세지 않는다.
- 과제 조건과 대안 경로가 실제 해당 목표에 맞고 공통 문구로 대체되지 않는다.
- 관계마다 종류·이유·조건·근거·상태를 확인할 수 있고, 추가 사고가 필요한 관계에는 그 내용을 명시한다.
- 학교급만 보기에서 다른 학교급의 노드·선·건수가 내부 결과에 섞이지 않는다.
- 상세의 직접 링크, 뒤로 가기, 모바일·키보드 탐색, 화면 배치가 함께 동작한다.
- 초기 세 사례의 깊이와 정보가 보존되고, 재생성 후에도 수정 내용이 유지된다.
- 원문 대조, 수학적 자체 점검, 독립 검토, 학생 반응 검증을 사실에 맞게 각각 표시한다.

완료 보고에는 학교급별 검토 수, 수정한 내용 문제, 내부 관계 판단 결과와 남은 검증 과제를 제시한다. 문서 수나 연결선 수만으로 상세 분석의 완성도를 판단하지 않는다.
