## 기록 단위

분수·비·단위 조정의 실제 기록 절차는 [관찰 기록 양식](분수단위조정관찰기록.md)을 따른다. 최초 반응·재질문·도움 후 반응을 구별하고, 계산과 단위 설명을 각각 확인한다. 출판된 연구의 평정표 재계산은 자체 학생 자료로 집계하지 않는다.

외부 검토자는 확인한 발문·기대 설명·도구와 버전, 발견한 문제의 위치를 적는다. 일대일 시범에서 문구나 도구의 문제가 발견되면 수정 전후 과제를 보존하고 새 응답에서 확인한다. 소집단에서 도움 없이 사용할 수 있는지 보는 단계와 실제 수업 조건에서 적용하는 단계의 자료는 따로 집계한다. 이 표는 시범 대상을 정리한 것이며 참여자와 응답은 아직 확보되지 않았다.

### 문항별 판정과 수정 기록

DC-P14~DC-P21에서는 관찰 ID와 함께 문항의 어느 부분을 확인했는지 기록한다. 예를 들어 DC-P14의 눈금에서는 점의 위치, 한 구간의 크기, 경계 눈금 수를 따로 판단한다. DC-P21의 동전에서는 공정 모형, 각 시행 기록, 합친 기록에 대한 설명을 따로 판단한다.

| 기록 단위 | 남길 항목 |
|---|---|
| 제시 조건 | 자료 버전, 발문, 제시한 도구, 도움의 내용과 시점, 관찰한 수행 |
| 수행별 결과 | 확인한 설명, 수학적 오류, 해석을 보류한 응답, 무응답, 미실시를 구별한 원기록 |
| 집계 범위 | 제시 인원과 응답 인원, 각 부분의 판정 가능 인원, 제외 기준과 이유 |
| 수정 근거 | 어느 문구·도구·조건이 문제였는지, 근거가 된 응답이나 검토 의견, 수정 전후 버전 |
| 수정 후 확인 | 새 반응에서 같은 문제가 나타나는지, 달라진 수치·맥락·도움 여부, 추가로 확인할 점 |

검토자가 문항 결함을 발견하면 응답을 삭제하기 전에 영향받은 범위와 처리 이유를 남긴다. 목표와 맞는 수행을 확인할 수 있었는지 검토하고, 설명이 부족할 때는 가능한 해석을 구별한다. [교수설계 7판의 선정 평가·수정 대조](../data/literature_evidence/DICK_CAREY_2014_assessment_revision_review_notes.json)
