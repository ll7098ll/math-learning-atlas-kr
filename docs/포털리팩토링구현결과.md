# 수학 교육과정 포털 리팩토링 구현 결과

작성일: 2026년 10월 29일

[전면 리팩토링 계획](포털전면리팩토링계획.md)에 따라 전체 조망, 성취기준 찾기, 독립 상세, 연결 탐구와 위계 화면을 구현했다. 핵심 동선은 전체 구조 또는 검색에서 기준을 열어 본문을 읽고 원래 탐색 위치로 돌아오는 방식이다.

## 구현 내용

- 초등 세 학년군과 중학교 공식 학년군, 고교 네 과목군·15과목을 전체 조망에서 표시한다. 기준 펼쳐 보기에는 435개 코드와 제목이 모두 포함된다.
- 개별 기준의 직접 링크가 학교급 필터에 막히지 않는다. 상세에는 공식 원문, 핵심 의미, 사고와 관찰할 수행, 과제·대안 경로, 진단과 후속 발문, 관련 기준, 출처를 배치했다.
- 검색 조건과 펼침·스크롤·선택 기준의 초점을 방문 상태에 저장한다. 상세 목차는 기준 코드를 유지하는 절 링크를 사용한다.
- 연결 근거는 별도 탐구에서 읽는다. 같은 두 기준의 여러 설명을 보존하고 학교급별로 묶어 펼친다. 위계의 기존 여섯 경로와 AND 조건 계산을 유지했다.
- 초기 색인과 기준별 상세, 관계·위계 자료를 분리했다. 초기 데이터 파일은 345,627바이트로 기존 data.js 7,553,650바이트보다 약 95.4% 작다. 이는 데이터 파일 크기 비교이며 네트워크 환경별 체감 속도 측정값은 아니다.
- 대표 분석 3개의 경로와 넓이 사례의 과제 누락을 복원하고, 초등·중고등의 다른 사고·진단 구조를 이름 있는 필드로 정규화했다. 공식 적용범위 메모와 원문 보정 기록도 연결했다.
- 페이지 모듈, 데이터 조회, 라우트 상태, 공통 표시를 분리하고 현재 사용하지 않는 대형 data.js와 이전 CSS 두 파일을 제거했다.

## 개념 흐름 조망 추가

전체 조망의 기본 보기에 아홉 개념을 행으로, 초등·중학교·고등학교를 열로 맞춘 지도를 추가했다. 대표 기준 47개 참조와 기존 관계 25개를 사용하며 각 개념을 펼쳐 의미의 확장, 추가 사고, 실제 근거의 출발·도착 기준을 읽는다. 공식 학교급 구조와 435개 전체 목록은 조망 방식 탭에서 전환한다.

원본은 [개념 흐름 자료](../data/concept_strands.json)다. 자료의 원래 관계 유형과 적용 범위를 보존하고, 초등에서 고교로 직접 기록된 간접 확장을 중학교와 고교 사이의 직접 선수 관계로 바꾸지 않는다.

`scripts/test_concept_flows.mjs`에서 아홉 흐름·27개 학교급 구획·대표 기준·관계 식별자와 양 끝 기준·검색·영역 필터·설명 펼침·초기 자료의 지연 로딩을 검증했다. 실제 브라우저에서 상세 왕복 후 선택과 근거 펼침 상태의 복원을 확인했으며 360·768·1280·1440px 폭에서 가로 넘침 없이 표시된다.

## 전체 성취기준으로 개념 조망 확장

대표 아홉 흐름을 전체 분류로 확장했다. 초등 121개·중학교 60개·고등학교 254개 전체에 주 개념을 하나씩 부여하고, 46개 개념 묶음으로 내보낸다. 한 기준에서 여러 내용을 함께 다루는 경우에는 47개 추가 참조를 표시하며 전체 기준 수는 중복을 제외한 435개다.

분류 원본은 [전체 개념 분류](../data/concept_taxonomy.json)다. 기존 개별 분석의 사고 유형과 성취기준 내용을 대조해 분류를 고정했다. 분류의 기준은 연구용이며 공식 학교급·학년군·과목·영역 정보도 함께 보존한다. 고교의 문화·탐구 과정 기준도 포함한다.

각 학교급 칸에서 해당 개념의 모든 성취기준을 펼친다. 직접 분류된 기준이 없는 칸은 그 상태를 표시하고, 다른 개념에서 연결된 기준을 별도로 제공한다. 개념 선택 후에는 학교급 사이·같은 개념 안·다른 개념 사이의 관계와 특정 성취기준으로 근거를 좁힐 수 있다. 기존 성취기준 간 연결 기록 1,518개 전체에 접근할 수 있다.

자동 검사에서 모든 기준의 주 분류가 정확히 한 번씩 나타남을 확인했다. 435개 코드별 검색·고교 15과목 필터·전체 펼침·내부 및 외부 관계의 실제 양 끝 기준·개념 간 기초 연결을 검사했다. 브라우저에서도 435개 고유 주 기준과 46개 개념, 101개 학교급별 목록의 전체 펼침을 확인했다. 360·768·1280·1440px에서 페이지 가로 넘침과 콘솔 오류가 없었으며, 탐구 기준 검색 후 상세 왕복에서 펼침·선택 초점을 복원했다.
