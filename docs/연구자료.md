# 수학 사고 분석을 위한 연구 자료와 조사 순서

현재 집계와 로컬·공개 버전은 [현재 상태](STATUS.md)를 먼저 확인한다. 아래 문서는 초기 조사부터 2026년 11월 18일까지의 누적 연구 기록이며, 도입과 각 절의 날짜·출처 수·주장 수는 당시 범위를 나타낸다. 과거 수치를 현재 총계로 읽지 않고, 출처별 실제 읽기 범위와 남은 검토는 해당 원장에 따라 구분한다.

자료는 공식 학습 범위를 확인하는 교육과정, 수학적 의미를 분석하는 문헌, 학생의 사고를 조사한 연구, 교수 및 진단 자료로 나누어 사용한다. 각 자료가 뒷받침하는 주장과 아직 확인하지 않은 부분은 출처 데이터에 기록한다. 2026년11월5일 현재 Wilkins·Norton의 논문11쪽과 Thompson·Saldanha의 저자 초고46쪽을 전체 읽고, Virginia Tech의 도구와 Norton 외(2015) 검증 논문26쪽·부록, IES/WWC의2010년 분수 지도 가이드90쪽과 당시 검토 프로토콜8쪽, 김유경·방정숙(2014)의17쪽, 박선영·이광호(2018)의24쪽과Adding It Up8장의공식웹본문 인쇄255–312쪽·삽입 이미지7개, OpenStax의미분 도입3.1절·미적분의 기본정리5.3절 전체 웹본문과 삽입 자산23개, Introductory Statistics2e의8.3절·9장 도입/9.2절 전체 웹본문·표9.2·사진1개를 명시한 범위로 확인했다.11개 출처의 주장53건에 위치·지원 범위·한계를 [문헌 주장별 근거](문헌주장별근거.md)로 연결했다. 권고 근거의Minimal/Moderate와 학년 집단 간 차이·교과서 모델의 제시 방식을 자체 과제의 효과 검증으로 전용하지 않는다. 최종 출판본·개별 원연구·번역 동등성·가이드 효과크기 불일치의 후속 대조는 출처 대장에 구별했다.
