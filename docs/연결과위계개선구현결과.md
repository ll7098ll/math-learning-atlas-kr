# 연결과 위계 개선 구현 결과

작성일: 2026년 10월 29일

후속 반영: [전체 개념군 연결과 위계 확장 결과](전체개념군연결과위계확장결과.md). 46개 개념군 전체의 의미 확장 초안과 위계 미검토 상태 탐색을 추가했다. 아래의 세 시범군 범위 설명은 첫 개선 시점의 기록이다.

[실행 계획](연결과위계고도화및성능개선계획.md)의 로딩 구조 개선, 목표와 조건 보존, 전체 검색 입구, 경로 비교를 구현했다. 전체 435개 성취기준의 의미 연결을 탐색할 수 있으며, 과제별 위계의 내용 범위는 기존 세 개념군의 자체 점검 초안이다.

## 구현한 기능

- 상단 연결과 위계에 46개 개념과 435개 기준의 검색 입구를 추가했다. 코드 검색은 해당 기준으로 좁혀지며, 기록된 연결과 상세 분석으로 이동한다.
- 기준에서 위계를 열 때 대응하는 사고를 목표로 삼고, 그 사고가 포함된 경로를 선택한다. 고교 유리함수 기준은 반비례의 확장 경로로 열린다.
- 노드 설명과 목표 변경을 구별하고, 최근 목표를 브라우저에 최대 다섯 개 저장한다.
- 학교급 범위 밖 목표와 조건을 경계 노드로 표시한다. 목표를 다른 노드로 바꾸거나 AND의 일부 조건을 삭제하지 않는다.
- AND 합류 표시와 전체 조건 수를 제공한다. 정비례의 의미 확장과 필요 조건이 같은 AND 묶음에 들어 있던 기록은 두 개별 주장으로 분리했다.
- 두 경로의 공통 사고와 전용 사고를 비교한다. 정비례·반비례는 서로 다른 관계의 분기로 설명하고, 분수·넓이의 두 설명 경로와 구별한다.
- 과제의 조건, 의미 확장, 수업 제안을 선 종류별로 선택해 볼 수 있다. 설명 단계가 모든 학생에게 필수인 숙달 순서라는 뜻은 부여하지 않는다.
- 학교급 적용 시 경로·목표·선택 사고·관계 종류를 유지하고, 지도 탭 사이에서도 학교급 범위를 유지한다. 다른 경로에 없는 목표는 원래 목표로 돌아왔다는 설명을 표시한다.
- 선과 노드의 모바일 전환 기준을 520px로 맞추고, 위치 읽기와 선 갱신을 프레임 단위로 묶었다.

## 로딩 구조

| 항목 | 이전 | 구현 후 |
|---|---|---|
| 위계 전용 자료의 의존성 | 전체 관계 묶음 2,636,613바이트 | 위계·참조 관계·출처·검토 구조 51,137바이트 |
| 위계 직접 진입 | 전체 관계 파일을 기다림 | 전용 자료만 읽음 |
| 성취기준 상세와 연결 | 전체 관계 파일을 읽음 | 해당 기준의 관계 파일을 읽음 |
| 위계 자료의 주소 | 공용 파일과 버전 쿼리 | 내용 버전이 포함된 파일 경로 |
| 초기 표시 | 공통 로딩 문구 | 연결과 위계 제목과 준비 상태를 먼저 표시 |

크기는 압축 전 JSON 기준이다. 위계 전용 자료는 이전 의존 파일보다 약 98.1% 작다. 직접 진입에는 공통 검색 색인도 필요하며, 전체 개념 검색 입구에서는 별도로 개념 분류 자료를 읽는다. 전체 관계 파일은 개념 흐름의 근거와 기존 자료 보존을 위해 유지한다.

요청 중인 Promise와 성공 자료를 공유하고, 실패한 요청은 캐시에서 제거해 재시도할 수 있게 했다. 버전별 파일에는 브라우저 기본 캐시 정책을 적용하고, 최신 목록의 재검증 및 자료 버전 일치 검사는 유지했다. 장기 캐시 헤더나 서버 압축 적용을 가정하지 않는다.

## 검증 결과

기존 네 검사와 새 `scripts/test_pathways.mjs`가 통과했다. 배포용 소스에 병합된 개념 연결 지도 검사도 통과했다.

- 435개 상세, 15과목, 기존 전체 관계와 출처를 보존했다.
- 46개 개념과 435개 기준의 연결 진입, 1,518개 성취기준 간 관계의 접근성을 확인했다.
- 36개 학교급·경로 조합에서 원래 목표, 노드, 전체 관계와 AND 묶음이 유지된다.
- 새 위계 파일이 60KB 이내이며, 위계와 개별 기준 조회에 전체 관계 파일이 요청되지 않는다.
- 동시 요청 공유, 재진입 시 요청 재사용, 자료 버전 오류 후 재시도가 통과했다.
- 브라우저에서 반비례 선택 후 중학교 범위 적용, 다른 노드를 목표로 바꾼 뒤 고등학교 범위 적용, 의미 확장 선만 보기, 경로 비교, 고교 기준 코드 검색을 확인했다.
- 360·520·560·600·768·1280px에서 페이지 가로 넘침 없이 일곱 노드와 여섯 선이 표시되는 대표 비율 경로를 확인했다. 지도 안의 가로 탐색은 유지한다.

로컬 브라우저에서 자료가 캐시된 경로 전환 30회의 렌더 처리 중앙값은 14.6ms, p95는 21.3ms였다. 이는 라우트 처리부터 노드·선 생성 후 예약 프레임까지의 내부 측정이며, 실제 입력 지연 지표나 느린 모바일 환경의 배포망 측정은 아니다. 최초 위계 진입의 실제 배포망 p95와 계획의 1.5초 목표는 아직 검증하지 않았다.

## 연구와 검토의 남은 범위

과제별 위계는 28개 사고와 32개 관계의 세 개념군이다. 기존 관계 전체를 필수 선수 관계로 승격하지 않았다. 생성 자료에 관계별 검토 상태와 명시적인 AND 조건 묶음을 추가했으며, 검토 완료 상태를 올릴 때에는 검토자와 근거 기록이 필요하도록 검증 규칙을 보완했다.

6~10개 주요 개념군의 위계 작성, 46개 전체의 위계 분석, 독립 교사 검토와 실제 학생 반응 검증은 남아 있다. 현재의 435개 분류와 연결 접근성을 위계 검토 완료율로 표시하지 않는다.

## 소스와 배포

작업 중 다른 작업에서 개념 흐름 지도가 갱신되어, 배포용 소스는 `tmp/pathways-release`에서 최신 원격 변경과 병합했다. 이 폴더에는 병합한 실행 소스와 세 개의 자체 검사가 있다. 작업 폴더의 다른 변경은 보존했다.

기존 사이트의 소유자 전용 접근 범위를 유지해 [연결과 위계](https://math-learning-atlas-kr.gptpro2908176.chatgpt.site/#view=hierarchy)에 배포했다. 배포 상태는 성공이며 소스 커밋은 `39d5988752bd6d0f81c690676451711e35f741c1`이다.

실제 배포 브라우저에서도 46개 개념 입구, 반비례 경로 선택 후 중학교 범위 적용, 목표 유지, 범위 밖 두 사고와 AND 합류 표시를 확인했다. 이때 연결과 위계 입구의 렌더 처리는 단일 관측으로 543.5ms였고, 위계 자료의 원시 크기는 51,137바이트, 전송 크기는 응답 헤더를 포함해 13,077바이트였다. 공통 색인과 개념 분류에는 이미 HTTP 캐시가 있어, 이 값을 캐시 없는 사이트 전체 첫 방문 성능이나 p95로 해석하지 않는다.

배포 검증 화면은 `tmp/pathways-qa/deployed-pathways.png`에 보관했다. 최초 포장 시 시스템 Node가 비정상 종료되어, 앱 제공 Node로 같은 소스의 포장을 완료했다. 원격의 다른 작업은 병합했으며 강제 푸시는 사용하지 않았다.
